# tasks/BLOCKED.md

Tasks that cannot proceed without a human decision, per
`AGENT_CONSTITUTION.md` Section 10 checkpoints, or after 3 genuinely
different fix attempts failed (`DEVELOPMENT_WORKFLOW.md`, "When a task
fails"). Also used to record any deliberate, approved scope reduction
(`AGENT_CONSTITUTION.md` Section 3 — no silent feature loss).

Format per entry:
```
## TASK-XXX — <title>
Blocked since: <date>
Reason: <checkpoint required | repeated failure | scope decision needed>
What was tried: <if repeated failure>
What's needed to unblock: <specific question or decision needed>
```

(Empty at project start.)
