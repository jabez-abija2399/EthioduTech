# tasks/IN_PROGRESS.md

Tasks currently being worked. A task lives here from the moment work starts
until it passes every step of `DEVELOPMENT_WORKFLOW.md` and every criterion
in `QUALITY_GATES.md` Gate A — only then does it move to `COMPLETED.md`.

Format per entry:
```
## TASK-XXX — <title>
Started: <date>
Feature: FEAT-XXX
Requirements: REQ-XXX..
Current step in DEVELOPMENT_WORKFLOW: <DISCOVER|ANALYZE|...|RELEASE>
Notes: <anything relevant to resuming this task in a future session>
```

(Empty at project start — populate as work begins.)
