# Level 3 — CSS

## 🎯 What This Level Teaches

CSS (Cascading Style Sheets) is what makes websites **look good**.

This level teaches you:

- What CSS is and how it works
- How to connect CSS to HTML
- How to select elements for styling
- Colors, typography, and backgrounds
- The box model (padding, border, margin)
- CSS units (px, %, em, rem, vw/vh)
- Cascade, inheritance, and specificity
- Display and positioning
- Flexbox and Grid layouts
- Pseudo-classes and pseudo-elements
- Transitions, transforms, and animations
- CSS variables and modern functions

## Why This Comes After HTML

In Level 2, you learned HTML (the structure).

Now you will learn:

- How to **style** that structure
- How to make it **visually appealing**
- How to create **professional layouts**
- How to make it **responsive** (in Level 4)

Without CSS, your website is just plain text and images.

## Skills You Will Gain

After this level, you will be able to:

- Write clean, organized CSS
- Style any HTML element
- Create professional layouts with Flexbox and Grid
- Use colors, typography, and spacing effectively
- Add interactive hover effects and animations
- Use CSS variables for theming
- Debug CSS problems

## Project Progress

By the end of this level:

- ✅ You will have a fully styled business website
- ✅ You will have navigation, hero, cards, gallery, and footer styled
- ✅ You will have a consistent color system and typography
- ✅ You will be ready to make it responsive in Level 4
