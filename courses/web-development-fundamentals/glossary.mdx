# Glossary

## A

### Algorithm
A step-by-step set of instructions for solving a problem or completing a task.

### API (Application Programming Interface)
A structured way for one program to request information or actions from another system.

### Attribute
Additional information added to an HTML element to modify its behavior or provide metadata (e.g., `href`, `src`, `class`).

---

## B

### Browser
A software application used to access and view websites (e.g., Chrome, Firefox, Safari).

---

## C

### Client
A device or program that requests information or services from a server (e.g., your web browser).

### CSS (Cascading Style Sheets)
A language used to style and layout webpages (colors, fonts, spacing, positioning).

---

## D

### DOM (Document Object Model)
A programming interface that represents the structure of an HTML document as a tree of objects, allowing JavaScript to interact with the page.

---

## E

### Element
A complete HTML component, including the opening tag, content, and closing tag (e.g., `<p>Hello</p>`).

### Endpoint
A specific URL where an API can be accessed to perform an action or retrieve data.

---

## H

### HTML (HyperText Markup Language)
The standard language for creating the structure of webpages.

### HTTP (HyperText Transfer Protocol)
The protocol used for transferring data between a web browser and a server.

---

## J

### JavaScript
A programming language used to add interactivity and dynamic behavior to websites.

### JSON (JavaScript Object Notation)
A lightweight data format used to store and exchange data, often between a server and a client.

---

## L

### localStorage
A browser API that allows websites to store data persistently on the user's device.

---

## S

### Server
A computer or program that provides information or services to clients (e.g., a web server hosting a website).

### Selector
A pattern used in CSS to target specific HTML elements for styling (e.g., `.class-name`, `#id`, `p`).

### Semantic HTML
Using HTML elements that clearly describe their meaning and structure (e.g., `<header>`, `<nav>`, `<article>`, `<footer>`).

---

## U

### URL (Uniform Resource Locator)
The address of a resource on the web (e.g., `https://example.com/page`).

---

## V

### Viewport
The visible area of a webpage in a browser, which varies by device and screen size.

---

## R

### Responsive Design
An approach to web design that makes websites work well on all screen sizes (mobile, tablet, desktop).

---

## G

### Git
A version control system that tracks changes to code over time.

### GitHub
A platform for hosting and collaborating on Git repositories.

---

## A (continued)

### Accessibility (a11y)
The practice of making websites usable by everyone, including people with disabilities.

---

## S (continued)

### SEO (Search Engine Optimization)
The practice of improving a website to rank higher in search engine results.

### Performance
How fast and smoothly a website loads and responds to user interactions.

### XSS (Cross-Site Scripting)
A security vulnerability where attackers inject malicious scripts into webpages viewed by other users.

---
