# Level 1 — Understanding the Web

## 🎯 What This Level Teaches

Before writing HTML, you must understand **where your code will run** and **how the web works**.

This level teaches you:

- What the internet is and how it connects devices
- The difference between the internet and the web
- How websites are delivered from servers to browsers
- What URLs mean and how they work
- How to use browser DevTools to inspect websites

## Why This Comes After Computer Foundations

In Level 0, you learned about computers (hardware, software, files).

Now you need to understand:

- How computers **talk to each other** over the internet
- How your website files **travel** from your computer to users
- What happens when someone **opens your website** in a browser

This knowledge makes you a better developer because you understand the **full picture**, not just code syntax.
