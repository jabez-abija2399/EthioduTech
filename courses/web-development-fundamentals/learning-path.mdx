# Learning Path

## 🗺️ Your Journey from Beginner to Graduation

This course follows a **structured learning path** designed to build your skills progressively—from absolute beginner to independent web developer.

Each level builds on the previous one. Do not skip levels, even if some topics seem simple.

## The Path

```
LEVEL 0: Computer Foundations
        ↓
LEVEL 1: Understanding the Web
        ↓
LEVEL 2: HTML
        ↓
LEVEL 3: CSS
        ↓
LEVEL 4: Responsive Web Design
        ↓
LEVEL 5: JavaScript
        ↓
LEVEL 6: DOM & Browser
        ↓
LEVEL 7: JSON, Storage & APIs
        ↓
LEVEL 8: Debugging
        ↓
LEVEL 9: Git & GitHub
        ↓
LEVEL 10: Accessibility
        ↓
LEVEL 11: SEO
        ↓
LEVEL 12: Performance
        ↓
LEVEL 13: Security Fundamentals
        ↓
LEVEL 14: Professional Development
        ↓
FINAL PROJECT: Graduation
```

## Why This Order?

### LEVEL 0 — Computer Foundations

**Why first?** You cannot build websites without understanding computers, files, folders, and code editors.

**You will learn**:
- What is a computer?
- Hardware and software
- Files and folders
- Code editors
- Terminal basics
- What is programming?

**Project state**: Create your project folder and first HTML file.

---

### LEVEL 1 — Understanding the Web

**Why now?** Before writing code, you must understand how the web works.

**You will learn**:
- Internet vs. web
- Clients and servers
- Requests and responses
- URLs
- Browser DevTools

**Project state**: Create HTML document structure and add business content.

---

### LEVEL 2 — HTML

**Why now?** HTML is the foundation of every webpage.

**You will learn**:
- HTML tags and elements
- Document structure
- Headings, paragraphs, lists
- Links and images
- Semantic HTML
- Forms and validation
- Accessibility basics
- Metadata

**Project state**: Build the complete HTML structure of your business website.

---

### LEVEL 3 — CSS

**Why now?** HTML alone is not enough—you need styling and layout.

**You will learn**:
- CSS rules and selectors
- Colors, typography, backgrounds
- Box model
- CSS units
- Cascade, inheritance, specificity
- Display and positioning
- Flexbox and Grid
- Transitions, transforms, animations
- CSS variables

**Project state**: Style your website professionally.

---

### LEVEL 4 — Responsive Web Design

**Why now?** Your website must work on all screen sizes.

**You will learn**:
- Responsive design principles
- Media queries and breakpoints
- Responsive layouts
- Responsive images
- Mobile navigation

**Project state**: Make your website fully responsive.

---

### LEVEL 5 — JavaScript

**Why now?** Static websites are limited—you need interactivity.

**You will learn**:
- Variables and data types
- Operators
- Strings and template literals
- Conditions and loops
- Functions
- Arrays and objects

**Project state**: Add JavaScript to your project.

---

### LEVEL 6 — DOM & Browser

**Why now?** JavaScript must interact with your webpage.

**You will learn**:
- What is the DOM?
- Selecting and changing elements
- Events (click, input, submit)
- Event delegation
- Forms and validation

**Project state**: Make your website interactive (navigation, modals, forms).

---

### LEVEL 7 — JSON, Storage & APIs

**Why now?** Real websites work with data—from files, storage, and APIs.

**You will learn**:
- JSON (parse, stringify)
- localStorage
- Asynchronous JavaScript
- Fetch API
- Understanding APIs

**Project state**: Add dynamic data and API-powered features.

---

### LEVEL 8 — Debugging

**Why now?** You will encounter bugs—you must learn to fix them.

**You will learn**:
- Types of errors
- Console and DevTools debugging
- Breakpoints
- Error handling (try/catch)

**Project state**: Debug and improve your project.

---

### LEVEL 9 — Git & GitHub

**Why now?** Professional developers use version control.

**You will learn**:
- Git basics (init, add, commit)
- Git history (log, diff)
- GitHub (repositories, push, pull)
- Branches and merging
- Pull requests and code review

**Project state**: Manage your project with Git and host it on GitHub.

---

### LEVEL 10 — Accessibility

**Why now?** Your website must be usable by everyone.

**You will learn**:
- What is web accessibility?
- Keyboard navigation
- Accessible forms
- Visual accessibility
- ARIA and screen readers

**Project state**: Perform an accessibility audit and fix issues.

---

### LEVEL 11 — SEO

**Why now?** Your website should be discoverable via search engines.

**You will learn**:
- What is SEO?
- On-page SEO
- Images and SEO
- Social sharing (Open Graph)
- Local SEO

**Project state**: Optimize your website for search engines.

---

### LEVEL 12 — Performance

**Why now?** Fast websites provide better user experiences.

**You will learn**:
- What is web performance?
- Network performance
- Image performance
- CSS/JS performance
- Core Web Vitals

**Project state**: Measure and improve your website's performance.

---

### LEVEL 13 — Security Fundamentals

**Why now?** Even frontend code must be secure.

**You will learn**:
- Web security basics
- Trusting user input
- XSS and safe DOM updates
- HTTPS and security concepts

**Project state**: Perform a security review and fix vulnerabilities.

---

### LEVEL 14 — Professional Development

**Why now?** Professional code is clean, organized, and documented.

**You will learn**:
- Readable code and naming
- File organization
- Reusable code
- Code review
- Documentation (README)
- Learning independently
- Responsible AI use

**Project state**: Refactor, organize, and document your project.

---

### FINAL PROJECT — Graduation

**Why last?** You must demonstrate everything you have learned.

**You will**:
- Perform a full audit (HTML, CSS, JS, accessibility, SEO, performance, security)
- Refactor your code
- Complete your README
- Deploy your website
- Prepare a portfolio presentation
- Defend your project

**Project state**: Graduate with a complete, professional website.

## ⏱️ Estimated Time

Total course time: **~120 hours** (varies by learner pace)

Recommended pace:

- **Fast**: 2–3 hours/day → ~6–8 weeks
- **Moderate**: 1–2 hours/day → ~10–12 weeks
- **Slow**: 30–60 minutes/day → ~16–20 weeks
