# Assessment System

## 🎯 How You Will Be Assessed

This course uses a **multi-layered assessment system** to ensure you truly master each concept—not just memorize or copy.

Assessment happens at **five levels**:

1. **Practice** (per topic)
2. **Checkpoint** (per topic)
3. **Mastery** (per topic)
4. **Level Audit** (per level)
5. **Final Graduation** (entire course)

## 1. Practice (Per Topic)

**Purpose**: Build basic skill through guided and independent exercises.

**Format**:
- Exercise 1: Guided practice (follow the example)
- Exercise 2: Independent practice (similar but not identical)
- Exercise 3: Problem-solving (apply the concept in a new way)
- Challenge: Transfer task (use the concept in your project)

**Pass criteria**: Complete all exercises with reasonable accuracy.

**Example**:

Topic: HTML Links

- Exercise 1: Create a link to another page
- Exercise 2: Create an internal link (same page, different section)
- Exercise 3: Create an email link and a telephone link
- Challenge: Add navigation links to your project

---

## 2. Checkpoint (Per Topic)

**Purpose**: Verify you are ready for mastery.

**Format**:
- Knowledge questions (explain concepts)
- Practical tasks (write code)
- Problem-solving (debug or improve code)
- Project requirement (apply to your project)

**Pass criteria**: Demonstrate readiness for mastery (typically 80%+).

**If you fail**: You receive **targeted remediation** for the specific skill you struggled with—not a generic "try again."

---

## 3. Mastery (Per Topic)

**Purpose**: Prove you can use the concept independently.

**Format**:
- Knowledge demonstration (explain in your own words)
- Skill demonstration (write code without copying)
- Problem-solving challenge (solve a new problem)
- Project demonstration (apply to your project)
- Independence test (complete without following the lesson example)

**Pass criteria**: All five dimensions must be satisfied.

**If you fail**: You receive a **remediation path** targeting your weak skill.

**Mastery unlocks**: The next topic becomes available.

---

## 4. Level Audit (Per Level)

**Purpose**: Ensure you can integrate all skills from the level.

**Format**:
- Comprehensive knowledge check
- Practical project review
- Accessibility, SEO, performance, or security audit (depending on level)

**Pass criteria**: All level requirements met.

**Example** (Level 2 — HTML):

- Valid HTML structure
- Semantic elements used correctly
- Forms with validation
- Accessibility basics (alt text, labels, headings)

---

## 5. Final Graduation (Entire Course)

**Purpose**: Demonstrate complete, independent ability.

**Format**:
- Full project audit (HTML, CSS, JS, accessibility, SEO, performance, security)
- Code refactoring
- README completion
- Deployment
- Portfolio presentation
- Project defense (oral or written explanation)

**Pass criteria**: All graduation requirements met.

**Outcome**: You graduate with **evidence of ability**, not just a certificate.

---

## Assessment vs. Mastery

| Aspect          | Assessment                          | Mastery                              |
|-----------------|-------------------------------------|--------------------------------------|
| **Scope**       | Broader (quizzes, tasks, projects)  | Specific (per topic)                 |
| **Purpose**     | Measure overall progress            | Prove independent skill              |
| **Format**      | Mixed (quizzes, code, audits)       | Five dimensions (knowledge, skill, problem-solving, project, independence) |
| **Unlocks**     | Level completion                    | Next topic                           |
| **Remediation** | General feedback                    | Targeted skill remediation           |

---

## Grading Philosophy

This course does **not** use traditional letter grades (A, B, C).

Instead, each skill is either:

- **Mastered** (you can do it independently)
- **Not yet mastered** (you need more practice/remediation)

This ensures you focus on **learning**, not just scoring points.

---

## Using AI in Assessments

AI can assist your learning—but **you must demonstrate independent understanding**.

**Allowed**:

- Ask AI to explain concepts
- Request hints when stuck
- Use AI to review your code

**Not allowed**:

- Copy-paste AI code without understanding it
- Submit AI-generated code as your own work
- Let AI complete mastery challenges for you

**Rule**: Always **read**, **verify**, **test**, and **explain** any AI-generated code.
