# Topic Mastery: HTML Basics

## 🎯 Mastery Goal

Prove you can write HTML independently.

## 🧠 Knowledge Demonstration

Explain in your own words:

1. What is [key element]?
2. Why does it matter?
3. When would you use it?

## 💻 Skill Demonstration

Write HTML without looking at lessons:

- Task description
- Must be valid HTML

## 🧩 Problem-Solving Challenge

Fix this broken HTML:

- Multiple errors
- Must debug and correct

## 🛠️ Project Demonstration

Apply this to your project:

- Specific HTML component
- Must work independently

## 🚫 Independence Test

Do this without:

- Copying lesson examples
- Using AI to write code
- Following step-by-step

You may:

- Review MDN documentation
- Validate your HTML
- Debug your own work

You pass when:

- [ ] Knowledge explained clearly
- [ ] Valid HTML written
- [ ] Errors fixed correctly
- [ ] Project component complete
- [ ] No copying detected
