# Level 2 — HTML

## 🎯 What This Level Teaches

HTML (HyperText Markup Language) is the **structure of every webpage**.

This level teaches you:

- What HTML is and how it works
- How to structure a complete HTML document
- How to add text, links, images, and lists
- How to organize content with containers
- How to use attributes correctly
- How to work with file paths
- How to write semantic, accessible HTML
- How to build forms with validation
- How to add metadata for SEO

## Why This Comes After Web Foundations

In Level 1, you learned how the web works (internet, servers, browsers, URLs).

Now you will learn:

- The **language browsers understand** (HTML)
- How to **structure content** so browsers can display it
- How to make your website **accessible and searchable**

Without HTML, you have no website.
