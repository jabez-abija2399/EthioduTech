# Final Submission

## 🎯 Purpose

This document guides you through **submitting your final project** for graduation review.

---

## ✅ Before Submitting

Ensure you have completed:

- [ ] All 15 levels of the course
- [ ] Final project audits (HTML, CSS, JS, accessibility, SEO, performance, security)
- [ ] Code refactoring and organization
- [ ] README.md completed
- [ ] Project deployed to a public URL
- [ ] Portfolio presentation prepared
- [ ] Final checklist scored 80/100 or higher

---

## 📤 Submission Requirements

Submit the following:

### 1. GitHub Repository URL

Provide the link to your **public GitHub repository**:

```
https://github.com/your-username/your-business-website
```

Ensure:

- Repository is public (or accessible to reviewers)
- README.md is complete
- Commit history is meaningful

### 2. Deployed Website URL

Provide the link to your **live, deployed website**:

```
https://your-business-website.netlify.app
```

Or:

```
https://your-username.github.io/your-business-website
```

Ensure:

- Site loads without errors
- All features work
- Site is responsive

### 3. Portfolio Presentation

Submit your **portfolio presentation** in one of these formats:

- **Written**: PDF or Markdown document (2–4 pages)
- **Video**: 3–5 minute recording (upload to YouTube, Google Drive, or similar)
- **Live**: Schedule a presentation session (if applicable)

Your presentation must include:

- Project title and business description
- Live demo (show the deployed website)
- Key features explained
- Technical decisions explained
- Challenges faced and solutions
- Future improvements

### 4. Final Checklist Score

Include your **final checklist score** (from [checklist.mdx](./checklist.mdx)):

```
Total Score: ___ / 100
```

## 🕐 Submission Deadline

Submit your project by the deadline specified by your instructor or program.

Late submissions may be accepted with penalty (check program policy).

---

## 🔍 Review Process

After submission:

1. **Automated checks**: HTML validation, Lighthouse scores (accessibility, SEO, performance)
2. **Manual review**: Code quality, technical decisions, portfolio presentation
3. **Defense**: Oral or written Q&A (if required)

You will receive feedback within **5–10 business days**.

After submitting, you will receive a confirmation email/message.

If you do not receive confirmation within 48 hours, contact support.
