# Final Project Architecture

## 🎯 Purpose

This document defines the **final architecture** of your project—how files are organized, how code is structured, and how everything connects.

---

## 📁 File Structure

Your final project must follow this structure:

```
your-business-website/
├── index.html
├── about.html (optional, if multi-page)
├── css/
│   └── styles.css
├── js/
│   └── main.js
├── images/
│   ├── logo.png
│   ├── hero.jpg
│   ├── gallery-1.jpg
│   ├── gallery-2.jpg
│   └── ...
├── data/
│   └── business.json (optional, for static data)
├── README.md
└── .gitignore
```

## ⚙️ JavaScript Architecture

### js/main.js

Organize your JavaScript logically:

```javascript
/* ====================================
   1. DOM Elements (Cached Selectors)
   ==================================== */
const navToggle = document.querySelector('.nav-toggle');
const navMenu = document.querySelector('.nav-menu');
const contactForm = document.querySelector('#contact-form');
// ... more elements

/* ====================================
   2. State (if needed)
   ==================================== */
let isLoading = false;
let businessData = [];

/* ====================================
   3. Functions
   ==================================== */

// Navigation toggle
function toggleNav() {
  navMenu.classList.toggle('open');
}

// Form validation
function validateForm(event) {
  event.preventDefault();
  // Validation logic
}

// Fetch API data
async function fetchBusinessData() {
  try {
    isLoading = true;
    // Fetch logic
  } catch (error) {
    // Error handling
  } finally {
    isLoading = false;
  }
}

// Render dynamic content
function renderContent(data) {
  // Rendering logic
}

/* ====================================
   4. Event Listeners
   ==================================== */
navToggle.addEventListener('click', toggleNav);
contactForm.addEventListener('submit', validateForm);

/* ====================================
   5. Initialization
   ==================================== */
document.addEventListener('DOMContentLoaded', () => {
  fetchBusinessData();
  // Other initialization
});
```

## 🔗 File Connections

| File | Links To | Purpose |
|------|----------|---------|
| `index.html` | `css/styles.css` | Load styles |
| `index.html` | `js/main.js` | Load JavaScript |
| `index.html` | `images/*` | Display images |
| `js/main.js` | DOM (HTML) | Manipulate page |
| `js/main.js` | API (external) | Fetch data |
| `README.md` | Deployment URL | Link to live site |
