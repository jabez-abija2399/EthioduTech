# Level 0 — Computer Foundations

## 🎯 What This Level Teaches

Before you can build websites, you must understand the **tools and environment** you will work in.

This level teaches you:

- What a computer is and how it works
- Hardware and software differences
- How files and folders are organized
- How to use a code editor
- How to navigate with the terminal
- What programming actually means

## Why This Comes First

You cannot write code if you:

- Do not understand files and folders
- Cannot save files in the right place
- Do not know how to open a code editor
- Have never used a terminal

This level ensures you have **computer literacy** before writing your first line of HTML.

## Skills You Will Gain

After this level, you will be able to:

- Explain what a computer is and how it works
- Navigate files and folders confidently
- Use a code editor to create and save files
- Use basic terminal commands
- Understand what programming means at a conceptual level

- ✅ You will have created your project folder
- ✅ You will have created your first HTML file
