# Level 5 — JavaScript

## 🎯 What This Level Teaches

JavaScript is what makes websites **interactive and dynamic**.

This level teaches you:

- What JavaScript is and what it can do
- Variables and data types
- Operators and expressions
- Strings and template literals
- Conditions (if/else, switch)
- Loops (for, while)
- Functions (including arrow functions)
- Arrays and array methods
- Objects and destructuring

## Why This Comes After Responsive Design

In Level 4, you learned responsive design (making layouts work on all screens).

Now you will learn:

- How to add **interactivity** to your website
- How to make it **respond to user actions**
- How to work with **data dynamically**

Without JavaScript, your website is static—no interactivity, no dynamic content.
