# Course Syllabus

## What This Syllabus Covers

This syllabus shows the **complete learning journey**, the **skills you will gain**, the **project milestones** you will hit, and the **mastery requirements** at each stage.

## Level Structure

The course is divided into **15 levels**, each building on the previous one.

### LEVEL 0 — Computer Foundations

**Goal**: Understand computers, files, editors, terminals, and basic programming thinking.

**Topics**:
- What is a computer?
- Hardware and software
- CPU, memory, and storage
- Operating systems and applications
- Files and folders
- File types and extensions
- File paths (absolute and relative)
- Code editors
- Terminal basics
- What is programming?

**Project Milestones**:
- PROJECT-001: Create project folder
- PROJECT-002: Create first HTML file

**Mastery Requirement**: You can navigate files, use a code editor, and explain basic computer concepts in your own words.

---

### LEVEL 1 — Understanding the Web

**Goal**: Understand how the internet and web work, including URLs, browsers, servers, and DevTools.

**Topics**:
- Internet vs. web
- Clients and servers
- Requests and responses
- URLs and their parts
- Browser DevTools

**Project Milestones**:
- PROJECT-003: Create HTML document structure
- PROJECT-004: Add business content

**Mastery Requirement**: You can explain how a webpage loads and use DevTools to inspect elements.

---

### LEVEL 2 — HTML

**Goal**: Build semantic, accessible HTML structures for your business website.

**Topics**:
- HTML tags and elements
- Document structure
- Headings, paragraphs, lists
- Links and images
- Containers (div, span)
- Attributes (id, class, etc.)
- File paths
- Semantic HTML (header, nav, main, section, article, aside, footer)
- Forms and validation
- Accessibility basics
- Metadata (title, meta description, favicon)

**Project Milestones**:
- PROJECT-005 to PROJECT-011: Navigation, images, lists, semantic structure, contact form, validation, metadata

**Mastery Requirement**: You can build a complete, semantic, accessible HTML page for your business.

---

### LEVEL 3 — CSS

**Goal**: Style your website professionally using modern CSS.

**Topics**:
- CSS rules and selectors
- Colors, typography, backgrounds
- Box model (padding, border, margin)
- CSS units (px, %, em, rem, vw, vh)
- Cascade, inheritance, specificity
- Display and positioning
- Flexbox and Grid
- Pseudo-classes and pseudo-elements
- Transitions, transforms, animations
- CSS variables and modern functions (calc, min, max, clamp)

**Project Milestones**:
- PROJECT-012 to PROJECT-020: Stylesheet, color system, typography, layout, navigation, hero, cards, gallery, footer

**Mastery Requirement**: You can style a complete, responsive layout using Flexbox and Grid.

---

### LEVEL 4 — Responsive Web Design

**Goal**: Make your website work beautifully on all screen sizes.

**Topics**:
- Responsive design principles
- Media queries and breakpoints
- Responsive layouts (Flexbox, Grid)
- Responsive images
- Mobile navigation

**Project Milestones**:
- PROJECT-021 to PROJECT-023: Responsive layout, mobile navigation, image optimization

**Mastery Requirement**: Your website is fully responsive and mobile-friendly.

---

### LEVEL 5 — JavaScript

**Goal**: Add interactivity and logic to your website.

**Topics**:
- Variables and data types
- Operators
- Strings and template literals
- Conditions (if/else, switch)
- Loops (for, while)
- Functions (including arrow functions)
- Arrays and array methods (map, filter, find, reduce)
- Objects and destructuring

**Project Milestones**:
- PROJECT-024 to PROJECT-027: Business data, conditional behavior, dynamic rendering

**Mastery Requirement**: You can write JavaScript to manipulate data and control program flow.

---

### LEVEL 6 — DOM & Browser

**Goal**: Interact with the webpage dynamically using JavaScript.

**Topics**:
- What is the DOM?
- Selecting elements (querySelector)
- Changing content, attributes, styles, classes
- Creating and removing elements
- Events (click, input, submit, keyboard)
- Event object, preventDefault, bubbling, delegation
- Forms: reading values, validation, error/success messages

**Project Milestones**:
- PROJECT-028 to PROJECT-033: Interactive navigation, modal, tabs/filter, gallery, form interaction, booking request

**Mastery Requirement**: You can build interactive features that respond to user actions.

---

### LEVEL 7 — JSON, Storage & APIs

**Goal**: Work with data, store it in the browser, and fetch from APIs.

**Topics**:
- JSON (parse, stringify)
- localStorage
- Asynchronous JavaScript (promises, async/await)
- Fetch API
- Understanding APIs (endpoints, methods, responses)

**Project Milestones**:
- PROJECT-034 to PROJECT-038: JSON data, localStorage feature, async JS, Fetch, API-powered feature

**Mastery Requirement**: You can fetch data from an API and display it dynamically.

---

### LEVEL 8 — Debugging

**Goal**: Find and fix bugs confidently.

**Topics**:
- Types of errors (syntax, runtime, logic)
- Console and DevTools debugging
- Breakpoints and debugger
- Error handling (try/catch)
- Loading, error, and success states

**Project Milestones**:
- PROJECT-039 to PROJECT-040: Debug project, error-handling review

**Mastery Requirement**: You can systematically debug your own code.

---

### LEVEL 9 — Git & GitHub

**Goal**: Manage your project with version control and collaborate on GitHub.

**Topics**:
- Git basics (init, status, add, commit)
- Git history (log, diff, undo)
- GitHub (repositories, push, pull, clone)
- Branches and merging
- Pull requests and code review
- README and collaboration

**Project Milestones**:
- PROJECT-041 to PROJECT-046: Initialize Git, meaningful commits, GitHub repo, push, branches, merge workflow

**Mastery Requirement**: You can manage your project with Git and host it on GitHub.

---

### LEVEL 10 — Accessibility

**Goal**: Make your website usable by everyone, including people with disabilities.

**Topics**:
- What is web accessibility?
- Keyboard navigation and focus
- Accessible forms
- Visual accessibility (contrast, motion)
- ARIA and screen readers

**Project Milestones**:
- PROJECT-047 to PROJECT-050: Accessibility audit, keyboard audit, form accessibility, screen-reader review

**Mastery Requirement**: Your website passes a basic accessibility audit.

---

### LEVEL 11 — SEO

**Goal**: Make your website discoverable via search engines.

**Topics**:
- What is SEO?
- On-page SEO (title, meta description, headings, links)
- Images and SEO
- Social sharing (Open Graph)
- Local SEO

**Project Milestones**:
- PROJECT-051 to PROJECT-053: SEO audit, metadata optimization, local SEO

**Mastery Requirement**: Your website is optimized for search engines and social sharing.

---

### LEVEL 12 — Performance

**Goal**: Make your website fast and smooth.

**Topics**:
- What is web performance?
- Network performance (caching, reducing requests)
- Image performance (formats, lazy loading)
- CSS/JS performance
- Core Web Vitals (LCP, CLS, INP)

**Project Milestones**:
- PROJECT-054 to PROJECT-057: Performance measurement, image optimization, network optimization, Core Web Vitals review

**Mastery Requirement**: Your website scores well on performance metrics.

---

### LEVEL 13 — Security Fundamentals

**Goal**: Write safe, secure frontend code.

**Topics**:
- Web security basics
- Trusting user input
- XSS and safe DOM updates
- HTTPS, cookies, CSP concepts
- Third-party content risks

**Project Milestones**:
- PROJECT-058 to PROJECT-060: Security review, input safety, XSS/safe DOM review

**Mastery Requirement**: Your website follows security best practices.

---

### LEVEL 14 — Professional Development

**Goal**: Write clean, maintainable, professional code.

**Topics**:
- Readable code and naming
- File organization
- Reusable code
- Code review
- Documentation (README)
- Learning independently
- Responsible AI use

**Project Milestones**:
- PROJECT-061 to PROJECT-065: Refactor, organize files, improve documentation, complete README, prepare portfolio

**Mastery Requirement**: Your code is clean, documented, and ready for others to use.

---

### FINAL PROJECT — Graduation

**Goal**: Polish, deploy, and defend your project.

**Activities**:
- Full audit (HTML, CSS, JS, accessibility, SEO, performance, security)
- Refactoring
- GitHub cleanup
- README completion
- Deployment
- Portfolio presentation
- Project defense
- Graduation

**Project Milestones**:
- PROJECT-066 to PROJECT-070: Deploy, final audit, submission, defense, graduation

**Mastery Requirement**: You can explain, defend, and showcase your work independently.

---

## Mastery Requirements Summary

To complete this course, you must:

1. Pass **knowledge checks** for each topic
2. Complete **guided and independent practice**
3. Solve **problem-solving challenges**
4. Apply concepts to your **continuous project**
5. Demonstrate **independence** (not just copying)
6. Pass **topic mastery checks**
7. Complete **level audits**
8. Successfully **defend your final project**
