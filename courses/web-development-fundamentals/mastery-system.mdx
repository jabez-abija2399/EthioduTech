# Mastery System

## 🎯 What Is Mastery?

**Mastery** means you can **independently** use a concept—not just recognize it or copy an example.

In this course, you do not progress by simply finishing a lesson. You progress by **proving mastery**.

## The Five Dimensions of Mastery

To master a topic, you must demonstrate **five dimensions**:

### 1. Knowledge

**Can you explain the concept in your own words?**

Example (HTML Links):

- What is an HTML link?
- What is the difference between `href` and `target`?
- When would you use an internal link vs. an external link?

### 2. Practical Skill

**Can you actually use the concept?**

Example (HTML Links):

- Create a link to another page
- Create an internal link (same page, different section)
- Create an email link (`mailto:`) and a telephone link (`tel:`)

### 3. Problem Solving

**Can you solve a slightly different problem that was not copied directly from the lesson?**

Example (HTML Links):

> Add a "Back to Top" link at the bottom of your page that scrolls to the top when clicked.

This requires understanding **fragment identifiers** (`#top`), which may not have been explicitly taught.

### 4. Project Application

**Can you correctly apply the concept to your ongoing project?**

Example (HTML Links):

> Add navigation links (Home, About, Menu, Contact) to your business website.

### 5. Independence

**Can you complete the task without simply copying the lesson solution?**

Example (HTML Links):

> Create a new type of link (e.g., download link, external resource link) that was not shown in the lesson.

## What Happens If You Fail Mastery?

You do **not** simply get "Try again."

Instead, the system identifies **which skill dimension** you failed:

**Example feedback**:

> You understand what a class selector is, but you are having difficulty choosing between class and ID selectors.

Then you receive:

```
Failed Skill
    ↓
Targeted Review
    ↓
Small Practice
    ↓
New Practice
    ↓
Retry
    ↓
Mastery Check
```

This ensures you **improve the specific weak skill**, not just repeat everything.

## Mastery States

Each topic has a **mastery state**:

- **LOCKED**: Not yet available (prerequisites not met)
- **AVAILABLE**: Ready to start
- **IN_PROGRESS**: You are working on it
- **CHECKPOINT_READY**: Practice complete, ready for checkpoint
- **MASTERY_READY**: Checkpoint passed, ready for mastery
- **MASTERED**: All five dimensions demonstrated

---

## Mastery vs. Completion

| Aspect             | Completion                        | Mastery                              |
|--------------------|-----------------------------------|--------------------------------------|
| **Definition**     | Finished reading/watching         | Can use independently                |
| **Evidence**       | "I clicked Next"                  | "I built something with it"          |
| **Assessment**     | Quiz or checkbox                  | Five dimensions (knowledge, skill, problem-solving, project, independence) |
| **Progression**    | Does not unlock next topic        | Unlocks next topic                   |
| **Remediation**    | Generic "review lesson"           | Targeted skill remediation           |

## Mastery Challenges

Mastery challenges are **not** "recreate the lesson example."

They require **transfer**—using the concept in a new situation.

**Example**:

Lesson taught:

```html
<a href="menu.html">Menu</a>
```

Mastery challenge:

> Add a navigation link that takes users to the contact section **on the same page** and explain why you chose the URL/fragment structure.

This tests whether you understand **internal links** (`#contact`), not just copying.

## Using AI Responsibly in Mastery

AI can help you learn—but **you must demonstrate independent understanding**.

**Good use**:

- Ask AI to explain a concept you do not understand
- Request hints when stuck on a mastery challenge
- Ask AI to review your code and suggest improvements

**Bad use**:

- Copy-paste AI code without understanding it
- Let AI write your mastery challenge solution
- Submit AI-generated code as your own work

**Rule**: Always **read**, **verify**, **test**, and **explain** any AI-generated code before using it.

## Mastery Checklist

Before marking a topic as **Mastered**, ask yourself:

- [ ] Can I explain this concept in my own words?
- [ ] Can I write code using this concept without looking at the lesson?
- [ ] Can I solve a problem I have not seen before?
- [ ] Have I applied this to my project?
- [ ] Did I do it independently (not just copying)?

If **all** are true, you are ready for mastery.
