<Context>
Flexbox is fantastic for lining things up in a single row or a single column (one-dimensional layout). But what if you want to build a complex layout with both rows *and* columns simultaneously, like a photo gallery or a dashboard?
</Context>

<Objective>
By the end of this lesson, you will construct a basic CSS Grid using templates and tracks.
</Objective>

<Concept>
## The CSS Grid Container
Just like Flexbox, you activate Grid by setting a parent container to `display: grid;`. But unlike Flexbox, Grid allows you to explicitly define a framework of rows and columns called **tracks**.

- **`grid-template-columns`**: Defines the number of columns and their widths.
- **`grid-template-rows`**: Defines the number of rows and their heights.
- **`gap`**: Creates spacing between the grid items.

### The `fr` Unit
Grid introduces a powerful new unit: the **fractional unit (`fr`)**. It represents a fraction of the available space in the grid container.

```css
.gallery {
  display: grid;
  /* Creates 3 equal-width columns */
  grid-template-columns: 1fr 1fr 1fr; 
  /* Creates 2 rows: the first is 100px, the second fills remaining space */
  grid-template-rows: 100px 1fr;
  gap: 15px;
}
```
Once the tracks are defined, any direct children of the `.gallery` will automatically drop into the grid cells, filling them row by row!
</Concept>

<InteractiveSandbox type="prediction">
A developer writes the following CSS for a grid container:
```css
.dashboard {
  display: grid;
  grid-template-columns: 200px 1fr 1fr;
}
```
How many columns does this grid have, and what is the size of the first column?
</InteractiveSandbox>

<Feedback>
The grid has exactly 3 columns. The first column is fixed at `200px` wide (perhaps for a sidebar). The second and third columns will evenly split whatever space is remaining!
</Feedback>

<IndependentPractice>
You are building a card layout. Write the CSS to turn the `.card-grid` container into a grid with **4 equal columns** using the `fr` unit, and a gap of `20px` between the cards.
</IndependentPractice>

<Reflection>
With Grid, you define the "blueprint" of the layout on the parent container. The browser does the hard math of figuring out exactly how many pixels each fractional column should be!
</Reflection>
