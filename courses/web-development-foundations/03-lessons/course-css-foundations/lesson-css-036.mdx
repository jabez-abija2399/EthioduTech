<Context>
Not everyone uses a mouse or touchscreen to navigate the web. Many users—including power users, people with motor disabilities, and users with broken trackpads—navigate using the `Tab` key on their keyboard. If they can't see where they are on the screen, the website is broken for them.
</Context>

<Objective>
By the end of this lesson, you will ensure interfaces remain usable by maintaining focus outlines.
</Objective>

<Concept>
## The `:focus` Pseudo-class
When a user tabs to an interactive element (like a link or a button), the browser gives that element **focus**. By default, the browser draws a blue or black outline around it.

You can customize this outline using the `:focus` or `:focus-visible` pseudo-class in CSS:

```css
button:focus-visible {
  outline: 3px solid #ff00ff; /* A bright, custom focus ring */
  outline-offset: 4px; /* Pushes the ring slightly outside the button */
}
```

### The Accessibility Cardinal Rule
**Never write `outline: none;` without providing a visible replacement.**
If you remove the default focus outline because you think it looks ugly, keyboard users will completely lose track of where they are on your page. If you remove it, you *must* replace it with an equally visible background color, border, or custom outline.
</Concept>

<InteractiveSandbox type="debugging_challenge">
A developer thought the default browser outline was ugly, so they removed it. Now, keyboard users can't see which link is selected! Fix the CSS by replacing `none` with a visible `2px solid red` outline.

```css
a:focus {
  outline: none; /* <-- This breaks keyboard accessibility! */
}
```
</InteractiveSandbox>

<HintLadder>
- Level 1: What happens when you press the Tab key on this page?
- Level 2: Nothing visual happens, because the outline is set to `none`.
- Level 3: Change `none` to a visible style like `2px solid red`.
</HintLadder>

<Reflection>
Accessibility is an engineering requirement. Customizing focus rings allows you to make an interface keyboard-accessible while still matching your brand's specific design!
</Reflection>
