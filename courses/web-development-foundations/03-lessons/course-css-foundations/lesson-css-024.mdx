<Context>
The web is mostly text. Controlling how that text looks is crucial for readability and creating a visual hierarchy.
</Context>

</Objective>

<Concept>
## Core Typography Properties
CSS provides several properties to format text:
- **`font-family`**: Changes the typeface. Usually, you provide a list of fonts. The browser uses the first one it has installed.
  ```css
  p { font-family: "Helvetica", "Arial", sans-serif; }
  ```
- **`font-size`**: Changes how large the text is. It can be set in pixels (`px`), but modern styling prefers relative units like `rem` (relative to the root HTML font size) for accessibility.
- **`font-weight`**: Controls the thickness of the text. Values include `normal`, `bold`, or numeric values like `400` (normal) and `700` (bold).
- **`line-height`**: Controls the vertical space between lines of text.

### HTML vs CSS Hierarchy
Never use an `<h1>` in HTML *just* to make text large, and never use CSS to make a `<p>` look exactly like an `<h1>` if it should semantically be a heading. HTML provides the structural outline; CSS provides the visual design.
</Concept>
