<Concept>
## The Build Process
Building an interface from scratch follows the same logical order as the browser rendering it:
1. **Global Resets**: Apply `box-sizing: border-box;` and reset default body margins.
2. **Typography & Color**: Establish the baseline fonts, line-heights, and accessible background/foreground colors.
3. **Document Flow & Box Model**: Add padding to containers and margins between major sections.
4. **Major Layout**: Apply Flexbox or Grid to the macro-level containers (Header, Main, Footer).
5. **Micro Layout**: Align the individual items inside those containers (Navigation links, card contents).
6. **Responsive Adaptation**: Add media queries to shift the layout when the viewport becomes too narrow.
7. **Interaction & Accessibility**: Ensure links have visible `:focus` states for keyboard users.
</Concept>

<InteractiveSandbox type="debugging_challenge">
A developer built a responsive layout, but the text inside the main content area touches the edges of the screen on narrow viewports, making it hard to read. 

Which phase of the build process did they forget?
</InteractiveSandbox>

<Feedback>
They forgot the **Box Model** phase! They need to add `padding` to the main container so the text doesn't touch the browser edges.
</Feedback>

<IndependentPractice>
**Project: The Portfolio Grid**
You have been provided with semantic HTML containing a header, a hero section, an "About" section, and a "Projects" section with 4 project cards.

Your task is to write the CSS to achieve the following requirements:
1. Set the global font to a sans-serif typeface and ensure high color contrast.
2. Set all elements to use `border-box` sizing.
3. Use Flexbox to align the header navigation horizontally.
4. Add appropriate padding inside the sections.
5. Use CSS Grid to arrange the 4 project cards in a 2x2 grid.
6. Write a media query: If the screen is narrower than `600px`, the project cards should stack in a single column (1x4 grid), and the header navigation should stack vertically.
7. Ensure all buttons and links have a highly visible custom `:focus` outline.

*Test your solution by resizing the viewport and using the `Tab` key to navigate!*
</IndependentPractice>

<HintLadder>
- Level 1: Start from the top of the CSS file. Apply the universal selector `*` for `box-sizing`.
- Level 2: To make the header navigation stack on narrow screens, check the `flex-direction` inside your media query.
- Level 3: To make the Grid change from 2 columns to 1, redefine `grid-template-columns` inside the media query.
- Level 4: Don't forget the `:focus` pseudo-class on `a` and `button` tags!
</HintLadder>
