<Context>
A 3-column grid looks great on a large desktop monitor. But if a user views that same website on a narrow mobile phone, the 3 columns will be squished together and impossible to read. We need our CSS to adapt.
</Context>

<Objective>
By the end of this lesson, you will adapt layouts to different screen sizes using media queries.
</Objective>

<Concept>
## Media Queries
A **Media Query** is a conditional statement in CSS. It allows you to say: "Only apply these CSS rules IF the browser window matches a specific condition."

The most common condition is checking the width of the viewport.

```css
/* 1. Default styles (Mobile First) */
.gallery {
  display: grid;
  grid-template-columns: 1fr; /* 1 column on small screens */
}

/* 2. Media Query for larger screens */
@media (min-width: 800px) {
  /* These rules ONLY apply if the screen is 800px or wider */
  .gallery {
    grid-template-columns: 1fr 1fr 1fr; /* 3 columns on large screens */
  }
}
```
Notice that the media query doesn't change the HTML. It simply overrides the `grid-template-columns` rule when the screen is wide enough!
</Concept>

<InteractiveSandbox type="prediction">
Look at the following CSS:
```css
body { background-color: white; }

@media (min-width: 600px) {
  body { background-color: yellow; }
}

@media (min-width: 1000px) {
  body { background-color: blue; }
}
```
What color will the background be if the user's screen is 850px wide?
</InteractiveSandbox>

<Feedback>
It will be yellow! 850px is wider than 600px (so the yellow rule applies), but it is NOT wider than 1000px (so the blue rule is ignored).
</Feedback>

<IndependentPractice>
Write a media query that checks if the screen is at least `700px` wide. Inside that media query, change the `.nav-links` container to `display: flex;`.
</IndependentPractice>

<Reflection>
Responsive design isn't about creating a separate "mobile website" and "desktop website". It's about writing one set of HTML, and using media queries to adapt the layout to whatever space is available.
</Reflection>
