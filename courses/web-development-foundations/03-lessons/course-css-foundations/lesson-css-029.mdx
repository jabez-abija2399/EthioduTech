<Context>
Normal flow is great, but sometimes you need to break an element out of the flow entirely—for example, to pin a navigation bar to the top of the screen, or to place an "X" close button in the top right corner of a box.
</Context>

<Objective>
By the end of this lesson, you will position elements using absolute and relative positioning.
</Objective>

<Concept>
## The `position` Property
1. **`static` (Default)**: The element stays in normal document flow.
2. **`relative`**: The element stays in normal flow, but you can nudge it around using `top`, `right`, `bottom`, and `left`. Other elements around it *will not* move to fill the gap; they act as if the element is still in its original place.
3. **`absolute`**: The element is completely removed from normal flow! Other elements behave as if it doesn't exist. You can move it anywhere using `top`/`right`/`bottom`/`left`.

### The Golden Rule of Absolute Positioning
An `absolute` element positions itself relative to its **closest positioned ancestor**. If it can't find one, it positions itself relative to the entire page. 
To trap an absolute element inside a specific container, give that container `position: relative;`!
</Concept>

<HintLadder>

- Level 2: The container needs `position: relative`.
- Level 3: The button needs `position: absolute` and `right: 10px`.
</HintLadder>

<IndependentPractice>
1. Open your local editor. Create a `<div>` with the class `container` and place another `<div>` inside it called `box`.
2. Give both elements a height, width, and distinct background colors.
3. Give `.box` `position: absolute; top: 0; right: 0;`. Notice how it flies out of the `.container` to the top-right corner of the whole page!
4. Visually debug this layout failure. What is missing from `.container`?
5. Add `position: relative;` to the `.container` and watch the `.box` snap back inside.
</IndependentPractice>

<Reflection>
Absolute positioning is powerful, but use it sparingly! If you absolutely position everything, your layout will completely break on different screen sizes because nothing flows naturally anymore.
</Reflection>
