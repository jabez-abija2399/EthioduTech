<Context>
Colors define the personality of a website. However, if colors are chosen poorly, they can make a website completely unreadable for visually impaired users.
</Context>

<Objective>
By the end of this lesson, you will apply accessible color combinations to text and backgrounds.
</Objective>

<Concept>
## Color Properties
- **`color`**: Changes the text (foreground) color.
- **`background-color`**: Changes the background color of an element.

## Contrast and Accessibility
When placing text over a background, the contrast ratio between the two colors must be high enough to be legible. 

For example, light gray text on a white background is almost invisible. Dark gray text on a white background provides excellent contrast. 

*Accessibility Rule:* Never rely on color alone to convey meaning (e.g., making text red to indicate an error without also saying "Error"). Additionally, always check contrast ratios when designing a site.
</Concept>

<InteractiveSandbox type="repair">
A developer created an alert box, but the contrast makes it unreadable. Repair the CSS by changing the `color` property to a high-contrast value like `white` or `black`.

```css
.alert-box {
  background-color: darkred;
  color: red; /* <-- Poor contrast! */
}
```
</InteractiveSandbox>

<Feedback>
Changing the `color` to `white` creates a high contrast ratio against the `darkred` background, making the alert readable.
</Feedback>

<Reflection>
Accessible color choices are not a burden; they represent good engineering. High contrast makes interfaces easier to use for everyone, including someone trying to read a phone screen in bright sunlight!
</Reflection>
