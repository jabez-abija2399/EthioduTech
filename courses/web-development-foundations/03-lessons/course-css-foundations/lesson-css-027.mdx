<Context>
In the previous batch, we learned about the Box Model (margin, border, padding, content). But there is a hidden trap: by default, if you set a box to be 200px wide, and then add 20px of padding, the box actually becomes 240px wide! It grows!
</Context>

<Objective>
By the end of this lesson, you will apply box-sizing to control how padding affects element width.
</Objective>

<Concept>
## `box-sizing`
The `box-sizing` property tells the browser how to calculate the total width and height of an element.

1. **`content-box` (Default)**: The width you set only applies to the *content*. Any padding or borders are added *on top* of that width, making the element physically larger on the screen.
2. **`border-box`**: The width you set is the *total* width. If you add padding or borders, the browser shrinks the inner content area so the total physical width remains exactly what you set!

Almost all modern developers prefer `border-box` because it makes reasoning about layout sizes completely predictable.
</Concept>

<InteractiveSandbox type="prediction">
Look at this code. If you inspect `.box-a` in the browser, how wide will it actually be?
```css
.box-a {
  width: 100px;
  padding: 10px;
  box-sizing: content-box;
}
```
</InteractiveSandbox>

<Feedback>
It will be 120px wide! 100px for the content, plus 10px padding on the left, plus 10px padding on the right.
</Feedback>

<InteractiveSandbox type="repair">
A developer wants two boxes to fit perfectly side-by-side inside a 400px container. They set each box to `width: 200px`, but because they added `padding`, the second box drops to the next line! Fix the CSS so the boxes remain exactly 200px wide total.
```css
.half-box {
  width: 200px;
  padding: 20px;
  /* Add your fix here */
}
```
</InteractiveSandbox>

<HintLadder>
- Level 1: What property changes how the browser calculates total width?
- Level 2: You want the padding to be included inside the 200px limit, not added to it.
- Level 3: Add `box-sizing: border-box;` to force the total width to stay at 200px.
</HintLadder>

<Reflection>
Changing the box sizing model is usually one of the very first things developers do in a new CSS file. Predictable dimensions prevent layout chaos later!
</Reflection>
