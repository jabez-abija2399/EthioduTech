<Context>
When you build a website, you make mistakes. Sometimes you delete a file you need. Sometimes you break a feature that was working yesterday. Instead of naming files `index_v2_final_REAL.html`, professional developers use a **Version Control System** to track every change they make. The most popular version control system in the world is called **Git**.
</Context>

<Objective>
By the end of this lesson, you will initialize a local Git repository.
</Objective>

<Concept>
## What is Git?
Git is a program that runs on your computer. It watches your project folder and takes "snapshots" of your files over time. If you break your code, you can use Git to time-travel back to a previous snapshot!

## Initializing a Repository
To start using Git, you must open your terminal, navigate into your project folder, and tell Git to start watching it. You do this with the following command:

```bash
git init
```

This command creates a hidden folder called `.git` inside your project. This hidden folder is the **Git Repository**. It is where Git stores all the snapshots and history.

## Checking the Status
Once initialized, you can ask Git what it sees using:

```bash
git status
```

This is the most important command in Git. It tells you exactly what has changed, what files Git is watching, and what you need to do next.
</Concept>

<Reflection>
Git is entirely local to your computer. When you run `git init`, nothing is uploaded to the internet! You are simply telling your computer to start tracking the history of that specific folder.
</Reflection>
