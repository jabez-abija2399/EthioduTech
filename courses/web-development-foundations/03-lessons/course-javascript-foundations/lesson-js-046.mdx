<Context>
If you find yourself writing the exact same code in three different places, you have a problem. If the rules change, you have to find and fix that code in all three places! Instead, we can package that code up into a reusable block called a **function**.
</Context>

<Objective>
By the end of this lesson, you will define and invoke JavaScript functions with parameters.
</Objective>

<Concept>
## Defining a Function
A function is a named block of code that does one specific job. You **declare** it once, and then you can **invoke** (or call) it as many times as you want.

```javascript
// 1. Define the function
function sayWelcome() {
  console.log("Welcome to our application!");
}

// 2. Call the function
sayWelcome(); // Output: Welcome to our application!
sayWelcome(); // Output: Welcome to our application!
```

## Parameters and Arguments
Functions are much more useful when they can take inputs and adapt their behavior. We call these inputs **parameters** (the variables inside the definition) and **arguments** (the actual values you pass in).

```javascript
// 'name' is a parameter. It acts like a variable inside the function.
function greetUser(name) {
  console.log("Hello, " + name + "!");
}

greetUser("Alice"); // "Alice" is the argument. Output: Hello, Alice!
greetUser("Bob");   // "Bob" is the argument. Output: Hello, Bob!
```
</Concept>
