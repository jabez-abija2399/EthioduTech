<Context>
In the real world, data is rarely flat. A shopping cart doesn't just hold strings; it holds a list of items, and each item is an object with a name and a price. We often have to navigate through arrays of objects, or objects containing arrays!
</Context>

<Objective>
By the end of this lesson, you will safely access properties within nested objects and arrays of objects.
</Objective>

<Concept>
## Arrays of Objects
A very common pattern is an array where every item is an object.

```javascript
let inventory = [
  { name: "Apple", price: 1.50 },
  { name: "Banana", price: 0.75 }
];
```
To get the price of the banana, you must first access the array index, and *then* the object property:
```javascript
// 1. Get the second item in the array: inventory[1]
// 2. Get its price property: .price
console.log(inventory[1].price); // Outputs: 0.75
```

## Objects inside Objects
Objects can also contain other objects!
```javascript
let student = {
  name: "Carlos",
  address: {
    city: "Madrid",
    zip: "28001"
  }
};

// Chain the dots together!
console.log(student.address.city); // Outputs: "Madrid"
```
</Concept>

<InteractiveSandbox type="prediction">
Look at the following nested data structure:
```javascript
let order = {
  orderId: 994,
  customer: { name: "Sarah" },
  items: ["Shoes", "Socks", "Hat"]
};
```
Write the exact line of JavaScript code required to access the string `"Hat"`.
</InteractiveSandbox>

<HintLadder>
- Level 1: What is the name of the main variable? (`order`)
- Level 2: Which property of `order` holds the hat? (`items`)
- Level 3: `items` is an array. What index is "Hat" at?
- Level 4: The correct code is `order.items[2]`
</HintLadder>

<Reflection>
Accessing nested data requires careful, step-by-step reasoning. Don't guess! Read the data from the outside in: "First the array, then the object, then the property."
</Reflection>
