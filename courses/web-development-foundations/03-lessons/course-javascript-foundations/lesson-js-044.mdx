<Context>
Imagine you are building a website that displays 100 products. Do you want to copy and paste the same block of code 100 times? What if you later need to change the design? Instead of manual repetition, programmers use **loops** to automate repetitive tasks.
</Context>

<Objective>
By the end of this lesson, you will automate repetitive tasks by writing loops that iterate until a specific condition is met.
</Objective>

<Concept>
## The `for` Loop
A `for` loop is the most common way to repeat code a specific number of times. It consists of three parts separated by semicolons:
1. **Initial state**: Where does the loop start? (e.g., `let i = 0`)
2. **Condition**: How long should the loop keep running? (e.g., `i < 5`)
3. **Update**: What changes after each repetition? (e.g., `i = i + 1`, usually written as `i++`)

```javascript
// This loop will print the numbers 0, 1, 2, 3, 4
for (let i = 0; i < 5; i++) {
  console.log("Current number is: " + i);
}
```

## The `while` Loop
If you don't know exactly how many times a loop needs to run in advance, you use a `while` loop. It just keeps running as long as a condition is true.

```javascript
let fuel = 3;
while (fuel > 0) {
  console.log("Driving...");
  fuel = fuel - 1; 
}
console.log("Out of fuel!");
```
**Warning**: If you forget to decrease the `fuel`, the condition `fuel > 0` will *always* be true, causing an **infinite loop** that will crash your program!
</Concept>

<InteractiveSandbox type="prediction">
Predict exactly how many times the word "Hello" will be printed by this loop:
```javascript
for (let i = 1; i <= 3; i++) {
  console.log("Hello");
}
```
</InteractiveSandbox>

<Feedback>
It will print exactly 3 times! It starts at 1, runs. It becomes 2, runs. It becomes 3, runs (because `i <= 3` means "less than or EQUAL to 3"). It becomes 4, and the loop stops.
</Feedback>
