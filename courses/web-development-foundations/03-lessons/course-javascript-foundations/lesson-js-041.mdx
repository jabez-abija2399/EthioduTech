<Context>
Having variables is great, but programs need to *do* things with them. We need to add numbers, combine text, and compare values. This is what operators do.
</Context>

<Objective>
By the end of this lesson, you will evaluate and manipulate data using mathematical, string, and comparison operators.
</Objective>

<Concept>
## Math and String Operators
You can perform math just like on a calculator:
- Add (`+`), Subtract (`-`), Multiply (`*`), Divide (`/`)
```javascript
let total = 50 + 25; // 75
```
Interestingly, you can use the `+` operator on Strings too! This is called **concatenation**:
```javascript
let greeting = "Hello " + "World"; // "Hello World"
```

## Comparison Operators
Programs constantly need to ask questions about data. Comparison operators compare two values and *always result in a Boolean* (`true` or `false`).
- **Strict Equality (`===`)**: Are these two values exactly the same type and value?
- **Not Equal (`!==`)**: Are these two values different?
- **Greater Than (`>`), Less Than (`<`)**
```javascript
let isAdult = 18 === 18; // true
let isPasswordCorrect = "secret123" === "password"; // false
```
*(Note: Always use `===` (three equals) in JavaScript for checking equality, not `==` (two equals), as the latter has confusing rules about converting types!)*
</Concept>
