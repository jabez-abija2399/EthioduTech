<Context>
To do anything useful, our programs need to remember things. If a user types their name into a form, where does that name go? It goes into the computer's memory, stored inside a Variable.
</Context>

<Objective>
By the end of this lesson, you will store, retrieve, and update data in memory using variables and identify basic data types.
</Objective>

<Concept>
## Variables
A variable is like a labeled box in the computer's memory. You put data inside the box, and you can look inside the box later using the label.

In JavaScript, we create (declare) a variable using the `let` keyword:
```javascript
let score = 0;
```
Now, whenever the computer sees the word `score`, it knows we mean `0`. We can also update the box later:
```javascript
score = 10;
```

## Data Types
What kind of data can we put in the box? JavaScript has several basic types:
- **Numbers**: `42`, `3.14`
- **Strings**: Text wrapped in quotes. `"Hello"`, `'Alice'`
- **Booleans**: Exactly two values: `true` or `false`. (Like a light switch).
</Concept>
