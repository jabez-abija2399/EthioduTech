<Context>
No programmer writes perfect code on the first try. Writing code is only half the job; the other half is fixing it when it breaks. Debugging is not about randomly changing things until it works; it is a systematic scientific process.
</Context>

<Objective>
By the end of this lesson, you will systematically reproduce, isolate, and diagnose JavaScript errors.
</Objective>

<Concept>
## The Debugging Workflow
When you encounter a bug, follow these exact steps:

1. **Reproduce**: Make the bug happen consistently.
2. **Observe expected vs actual**: What did you *want* to happen? What *actually* happened? (e.g., "I expected 10, but got `NaN`").
3. **Isolate**: Find the exact line of code where the logic derails.
4. **Hypothesize**: Form a theory. "I think the loop is running one extra time."
5. **Inspect**: Use `console.log()` to print the values of variables right before the error happens to prove your theory.
6. **Fix and Verify**: Change ONE thing, run it again, and check the result.

### Reading Error Messages
If your program crashes, the browser or terminal will give you an error message. *Read it!*
- `ReferenceError: x is not defined`: You tried to use a variable that doesn't exist (maybe a typo?).
- `TypeError: Cannot read properties of undefined`: You tried to use dot notation (like `user.name`) on a variable that is currently `undefined`.
</Concept>

<InteractiveSandbox type="debugging_challenge">
A developer wrote a function to calculate the total price of an array of items. But it outputs `NaN` (Not a Number)!

```javascript
function getTotal(items) {
  let total; // BUG IS HERE
  for (let i = 0; i < items.length; i++) {
    total = total + items[i].price;
  }
  return total;
}

let cart = [ {price: 10}, {price: 5} ];
console.log(getTotal(cart)); // Outputs NaN
```
</InteractiveSandbox>

<HintLadder>
- Level 1: Look at the variable `total` before the loop starts. What is its value?
- Level 2: Because it was declared without a value (`let total;`), its value is `undefined`.
- Level 3: In the first loop, the computer tries to do `undefined + 10`. Math with `undefined` results in `NaN`.
- Level 4: Fix it by giving `total` a starting value of 0: `let total = 0;`
</HintLadder>
