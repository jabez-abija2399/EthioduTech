<Context>
Writing a loop is easy. Figuring out exactly what a loop is doing while it is running is much harder. To debug complex programs, you must be able to trace a loop's state in your head before relying on the computer.
</Context>

<Objective>
By the end of this lesson, you will trace the execution of a loop step-by-step to predict its final output.
</Objective>

<Concept>
## Tracing Loop Execution
Tracing means manually acting like the computer and writing down the value of variables at each step.

Consider this loop:
```javascript
let total = 0;
for (let i = 1; i <= 3; i++) {
  total = total + i;
}
console.log(total);
```

Let's trace it:
- **Before loop**: `total` is 0.
- **Iteration 1**: `i` is 1. Condition (1 <= 3) is true. `total` becomes `0 + 1` (which is 1). `i` updates to 2.
- **Iteration 2**: `i` is 2. Condition (2 <= 3) is true. `total` becomes `1 + 2` (which is 3). `i` updates to 3.
- **Iteration 3**: `i` is 3. Condition (3 <= 3) is true. `total` becomes `3 + 3` (which is 6). `i` updates to 4.
- **Iteration 4**: `i` is 4. Condition (4 <= 3) is FALSE. The loop stops!
- **Final Output**: 6
</Concept>

<InteractiveSandbox type="debugging_challenge">
A developer wrote a loop to print the even numbers 2, 4, and 6. 
Instead, it prints 2, 4, 6, 8, 10, 12... forever! The program crashes. 

```javascript
let number = 2;
while (number <= 6) {
  console.log(number);
  // They forgot something here!
}
```
What is wrong with the code?
</InteractiveSandbox>

<HintLadder>
- Level 1: Look at the condition: `number <= 6`.
- Level 2: Look at the variable `number`. What is its value at the end of the first loop?
- Level 3: The value of `number` is always 2! Because it never changes, the condition is always true. You must add `number = number + 2;` inside the loop.
</HintLadder>

<IndependentPractice>
Trace the following loop on paper or in your head. 
```javascript
let score = 10;
for (let i = 0; i < 2; i++) {
  score = score - 2;
}
```
What is the final value of `score` when the loop finishes entirely?
</IndependentPractice>

<Reflection>
Whenever a loop behaves unexpectedly, do not just guess and change random characters. Stop, write down the variables, and trace it exactly the way the computer reads it.
</Reflection>
