<Context>
When you reload a web page, all your JavaScript variables are reset to their initial state. If you want data to survive a page refresh, you must store it somewhere. The simplest place is the browser's LocalStorage.
</Context>

<Objective>
By the end of this lesson, you will save and retrieve simple data strings using the browser's LocalStorage API.
</Objective>

<Concept>
## What is LocalStorage?
LocalStorage is a tiny database built directly into the user's browser. It allows you to save data that will persist even if the user closes the tab or restarts their computer.

## Setting and Getting Items
LocalStorage works like a dictionary using keys and values. **Both the key and the value must be strings.**

```javascript
// Saving data
localStorage.setItem('username', 'Alice');
localStorage.setItem('theme', 'dark');

// Retrieving data
const storedName = localStorage.getItem('username');
console.log(storedName); // Outputs "Alice"

// Removing data
localStorage.removeItem('theme');
```
</Concept>

```javascript

```

<Reflection>
LocalStorage is perfect for user preferences like themes or simple settings. However, it is visible to anyone using that browser, so NEVER store passwords or sensitive data in it!
</Reflection>
