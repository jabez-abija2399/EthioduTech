<Context>
Now that you understand the concept of a Promise, it is time to actually fetch real data over the network. We will use the browser's built-in `fetch` API to get data from a third-party server.
</Context>

<Objective>
By the end of this lesson, you will fetch data from a third-party REST API and handle the JSON response.
</Objective>

<Concept>
## The Fetch API
The `fetch()` function takes a URL and returns a Promise. When you call `fetch()`, the browser sends a request across the internet. This takes time! 

The browser does not stop and wait. It immediately moves to the next line of your code. We use `.then()` to tell the browser: *"Whenever the server finally replies, execute this block of code."* When that Promise resolves, it gives us a `Response` object.

## Parsing JSON Data
The `Response` object is not the raw data; it is an HTTP response. To get the actual JSON data out of it, we must call the `.json()` method on it. Because reading data from a network stream also takes time, `.json()` *also* returns a Promise!

Therefore, a standard fetch request looks like a chain of two `.then()` blocks:

```javascript
fetch('https://jsonplaceholder.typicode.com/users/1')
  .then(function(response) {
    // 1. We got the response from the server!
    // Now, parse the JSON body...
    return response.json(); 
  })
  .then(function(data) {
    // 2. The JSON is fully parsed!
    // We can finally use the data as a normal JavaScript object.
    console.log(data.name);
  });
```
</Concept>

- Level 3: Inside the second `.then()`, `data` is an array. Loop over it with a `for` loop.
- Level 4: Inside the loop, append to the DOM: `list.innerHTML += '<li>' + data[i].name + '</li>';`
