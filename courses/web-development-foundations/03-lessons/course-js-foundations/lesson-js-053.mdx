<Concept>
## The "Silent" Failure
Sometimes JavaScript throws a loud, red error in the console. Other times, it just silently does the wrong thing. This usually happens when dealing with dynamically typed values.
For example, adding a string to a number:
```javascript
const score = 10;
const points = "5";
console.log(score + points); // Outputs "105", not 15!
```

## Undefined vs Null
- `undefined`: A variable was declared but never assigned a value.
- `null`: A variable was intentionally assigned an "empty" value.
If you see `Cannot read properties of undefined`, it means you are trying to access a property on a variable that has no value.
</Concept>

<InteractiveSandbox type="browser_preview">
The following code is supposed to calculate the total price of items in a shopping cart, but it is returning `NaN` (Not a Number). 
Open the console, find the bug, and fix it!

```javascript
const cart = [
  { item: "Apple", price: 1.50 },
  { item: "Banana", price: 0.75 },
  { item: "Orange" }
];

let total = 0;
for (let i = 0; i < cart.length; i++) {
  total += cart[i].price;
}
console.log("Total is: " + total);
```
</InteractiveSandbox>

<Feedback>
The third item in the array, "Orange", is missing a `price` property. When the loop tries to access `cart[2].price`, it gets `undefined`. Adding `undefined` to a number results in `NaN`. To fix it, you must add `price: 1.00` (or any number) to the Orange object.
</Feedback>

<IndependentPractice>
1. Identify a previous project or sandbox where you had a bug.
2. Intentionally recreate the bug.
3. Open your browser's Developer Tools (Console).
4. Observe the exact error message or incorrect output.
5. Fix the bug and verify the output is correct.
</IndependentPractice>
