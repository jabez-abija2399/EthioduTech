<Context>
Forms are the primary way users send data to a website. By default, submitting an HTML form reloads the entire page. In modern web development, we often want to intercept that submission and handle the data using JavaScript instead.
</Context>

<Objective>
By the end of this lesson, you will capture and process form submissions dynamically without page reloads.
</Objective>

<Concept>
## Preventing Default Behavior
When you click a submit button inside a `<form>`, the browser's default behavior is to send a request and reload the page. We can stop this using the event object passed to our event listener.

```javascript
const form = document.querySelector('#my-form');

form.addEventListener('submit', function(event) {
  event.preventDefault(); // Stops the page from reloading!
  console.log("Form submitted dynamically!");
});
```

## Capturing Input Values
Once you stop the reload, you usually want to read what the user typed. You can select the `<input>` element and read its `value` property.

```javascript
const usernameInput = document.querySelector('#username');
console.log(usernameInput.value);
```
</Concept>

<HintLadder>
- Level 1: Have you selected the `form`, the `input`, and the `ul`?
- Level 2: Make sure your event listener is listening for `'submit'`, not `'click'`.
- Level 3: Inside your listener, call `event.preventDefault();`.
- Level 4: To add an item, you can create a string of HTML and append it: `ul.innerHTML += '<li>' + input.value + '</li>';`
- Level 5: Don't forget to clear the input: `input.value = '';`
</HintLadder>

<Reflection>
By handling forms with JavaScript, you take control away from the browser. This allows you to validate data, show error messages, and update the UI instantly without the disruptive flash of a page reload.
</Reflection>
