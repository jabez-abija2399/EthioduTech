<Concept>
## The Document Object
When a browser loads an HTML file, it creates a JavaScript object that represents the page. This object is called `document`.

## Query Selectors
The most powerful way to select elements is using CSS selectors inside JavaScript.
- `document.querySelector('selector')`: Returns the *first* element that matches the CSS selector.
- `document.querySelectorAll('selector')`: Returns a list of *all* elements that match.

Examples:
```javascript
// Select by ID
const header = document.querySelector('#main-header');

// Select by Class
const activeTab = document.querySelector('.tab-active');

// Select by Tag
const firstButton = document.querySelector('button');
```
