<Context>
LocalStorage is incredibly useful, but it has one major limitation: it can only store strings. What if you want to save a complex array of tasks or an object full of user data? You must convert that data into a string format first.
</Context>

<Objective>
By the end of this lesson, you will convert objects and arrays to JSON for storage and parse them upon retrieval.
</Objective>

<Concept>
## JSON (JavaScript Object Notation)
JSON is a standard text format for representing structured data. It looks exactly like JavaScript objects and arrays, but it is purely a string of text.

## Serialization: Object to String
To save an object or array to LocalStorage, you must "serialize" it (turn it into a JSON string) using `JSON.stringify()`.

```javascript
const user = { name: "Bob", score: 42 };
// Convert to string
const userString = JSON.stringify(user); 
console.log(typeof userString); // "string"

localStorage.setItem('userData', userString);
```

## Parsing: String to Object
When you retrieve the string from LocalStorage, you cannot use it as an object until you "parse" it back into JavaScript data using `JSON.parse()`.

```javascript
const storedString = localStorage.getItem('userData');
// Convert back to object
const parsedUser = JSON.parse(storedString); 

console.log(parsedUser.name); // "Bob"
```
</Concept>

<HintLadder>
- Level 1: First, `const taskString = JSON.stringify(tasks);`
- Level 2: Save it: `localStorage.setItem('myTasks', taskString);`
- Level 3: Retrieve it: `const retrievedString = localStorage.getItem('myTasks');`
- Level 4: Parse it: `const parsedTasks = JSON.parse(retrievedString);`
- Level 5: Log it: `console.log(parsedTasks[0].title);`
</HintLadder>

<Reflection>
Serialization is a fundamental concept in computing. Whether you are saving to LocalStorage, sending data to a server over a network, or reading a configuration file, data must almost always be converted to text to travel, and then parsed back into structured data to be used.
</Reflection>
