</Context>

<Objective>
By the end of this lesson, you will implement the planned responsive HTML/CSS structure.
</Objective>

<Concept>
## Building Incrementally
Do not try to write all your HTML and all your CSS at once. Build one section at a time.
1. Write the semantic HTML for a section (e.g., the Header).
2. Add classes and IDs.
3. Write the CSS to style that section.
4. Test it in the browser.
5. Commit the code using Git!

## Responsive Design from the Start
Remember that your users will view your project on phones, tablets, and desktops. Use flexible layouts (Flexbox and Grid) and relative units (%, rem, vw) rather than fixed pixel widths. Use media queries (`@media`) to adjust the layout when the screen size changes.

## Accessibility Matters
As you write your HTML, remember to:
- Use semantic tags (`<nav>`, `<main>`, `<article>`, `<button>`).
- Ensure all images have descriptive `alt` attributes.
- Ensure forms have associated `<label>` elements.
- Maintain sufficient color contrast.
</Concept>

<HintLadder>
- Level 1: Do you remember how to start an HTML document?
- Level 2: Don't forget the `<title>` inside the `<head>`!
- Level 3: 
```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>My Capstone</title>
</head>
<body>
</body>
</html>
```
</HintLadder>

<IndependentPractice>
This is the main build phase for your user interface!
1. Create your `index.html` and `style.css` files.
2. Build the visual structure of your project based on your wireframes.
3. Use CSS to implement your layout, typography, and colors.
4. **Git Workflow**: Commit your code incrementally. Do not make one massive commit at the end of the day. Commit every time you finish a logical section (e.g., `git commit -m "Build responsive navigation bar"`).
</IndependentPractice>
