<Context>
Every HTML document needs a specific structure to be understood correctly by a web browser. Think of it like the envelope of a letter—it tells the browser how to read what's inside.
</Context>

<Objective>
By the end of this lesson, you will construct a valid HTML5 document skeleton including DOCTYPE, html, head, title, and body tags.
</Objective>

<Concept>
## The HTML Skeleton
A valid HTML page always contains these core elements:
1. `<!DOCTYPE html>`: Tells the browser this is an HTML5 document.
2. `<html>`: The root element wrapping everything.
3. `<head>`: Contains metadata (like the title), not visible on the page itself.
4. `<body>`: Contains the actual visible content.
</Concept>

<GuidedPractice>
## Let's Build the Skeleton
Look at the following code snippet.
```html
<!DOCTYPE html>
<html>
  <head>
    <title>My First Real Page</title>
  </head>
  <body>
    <!-- Visible content goes here -->
  </body>
</html>
```
Notice how the `<head>` and `<body>` are siblings inside the `<html>` tag.
</GuidedPractice>

<Feedback>

</Feedback>

<Reflection>

</Reflection>
