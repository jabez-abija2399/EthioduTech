<Context>
So far, HTML has been a one-way street: you show content to the user. Forms make the web interactive, allowing the user to send information back.
</Context>

<Objective>
By the end of this lesson, you will construct a functional HTML form with varied input types and labels.
</Objective>

<Concept>
## The Form Container
All inputs must be wrapped in a `<form>` tag. 

## Inputs and Labels
- **`<input>`**: An interactive element. The `type` attribute defines what kind of input it is (e.g., `type="text"`, `type="email"`, `type="checkbox"`). Like images, inputs do not have closing tags.
- **`<label>`**: Text that explains what the input is for.

**Accessibility Rule:** Every input must have an associated label! This is done by matching the `for` attribute on the label to the `id` attribute on the input.

```html
<form>
  <label for="username">Your Name:</label>
  <input type="text" id="username">
  
  <button type="submit">Send</button>
</form>
```
When you click a `type="submit"` button, the browser gathers the data in the form. (We will learn how to process that data in backend courses!).
</Concept>

</InteractiveSandbox>

<Feedback>
Because the label is properly linked to the input via the `for` and `id` attributes, clicking the label text will automatically focus the text box!
</Feedback>

<IndependentPractice>
Create a small form that asks for a user's Email. It should have a label (linked correctly), an input of type `email`, and a submit button.
</IndependentPractice>

<Reflection>
Forms are the gateway to interactive web apps. Connecting your labels and inputs properly ensures everyone can use them easily.
</Reflection>
