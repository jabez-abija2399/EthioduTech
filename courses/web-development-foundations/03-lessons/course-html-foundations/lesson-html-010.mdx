<Context>
The web is called a "web" because pages are connected to each other via links.
</Context>

<Objective>
By the end of this lesson, you will connect multiple HTML documents together using anchor tags.
</Objective>

<Concept>
## The Anchor Tag
To create a link, we use the anchor tag `<a>`. It requires an attribute called `href` (Hypertext Reference) to tell the browser where to go.

```html
<a href="https://example.com">Visit Example</a>
```
The text between the opening and closing tag ("Visit Example") is what the user clicks on.
</Concept>

<InteractiveSandbox type="prediction">
What will happen if a user clicks the text "Read More" in this code?
```html
<a href="about.html">Read More</a>
```
</InteractiveSandbox>

<Feedback>
The browser will navigate to a file named `about.html`.
</Feedback>

<GuidedPractice>
Write an anchor tag that links to `contact.html` with the clickable text "Contact Us".
</GuidedPractice>

<Reflection>
Links can point to entirely different websites (URLs) or to other HTML files inside your own project!
</Reflection>
