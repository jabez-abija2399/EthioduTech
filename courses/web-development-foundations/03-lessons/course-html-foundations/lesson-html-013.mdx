<Context>
The web is visual. Adding images breaks up text and conveys important information. However, we must ensure everyone can understand our images, even if they can't see them.
</Context>

<Objective>
By the end of this lesson, you will embed images using the img tag and provide meaningful alt attributes.
</Objective>

<Concept>
## The Image Tag
Images are embedded using the `<img>` tag. Notice that it does not have a closing tag!

```html
<img src="puppy.jpg" alt="A golden retriever puppy sitting in grass">
```

1. **`src` (Source)**: This is a file path (like we learned in Lesson 11) telling the browser where to find the image.
2. **`alt` (Alternative Text)**: This describes the image for users relying on screen readers, or in case the image fails to load.

**Important Accessibility Rule**: If an image is purely decorative (e.g., a swirl graphic), you still include the alt attribute, but leave it empty: `alt=""`. If the image conveys meaning, write exactly what a user needs to know. You don't need to write "Image of", screen readers say that automatically.
</Concept>
