<Context>
Sometimes information needs to be presented in a grid of rows and columns—like a schedule or a dataset.
</Context>

<Objective>
By the end of this lesson, you will display tabular data using HTML table, tr, th, and td elements.
</Objective>

<Concept>
## Building a Table
Tables in HTML are built row by row.
- `<table>`: The container for the entire grid.
- `<tr>` (Table Row): Defines a single horizontal row.
- `<th>` (Table Header): A special cell used for column or row headings. It implies meaning for the data below or beside it.
- `<td>` (Table Data): A standard data cell.

*Crucial Rule:* Never use a `<table>` just to position images and text side-by-side on your page layout. Tables are strictly for displaying tabular data.
</Concept>

<GuidedPractice>
## A Simple Schedule
Here is how you build a table with one header row and one data row:
```html
<table>
  <tr>
    <th>Day</th>
    <th>Activity</th>
  </tr>
  <tr>
    <td>Monday</td>
    <td>Running</td>
  </tr>
</table>
```
</GuidedPractice>

<InteractiveSandbox type="debugging_challenge">
Find the structural error in this table:
```html
<table>
  <tr>
    <th>Name</th>
    <th>Score</th>
  </tr>
  <td>Alice</td>
  <td>95</td>
</table>
```
</InteractiveSandbox>

<HintLadder>
- Level 1: Are all cells inside a row?
- Level 2: Look at the data cells for Alice.
- Level 3: The `<td>` elements for Alice and 95 are missing their parent `<tr>` tag. They must be inside a row!
</HintLadder>

<Reflection>
Using `<th>` instead of `<td>` for headings ensures screen readers can announce the correct column name as a user navigates through a massive data table.
</Reflection>
