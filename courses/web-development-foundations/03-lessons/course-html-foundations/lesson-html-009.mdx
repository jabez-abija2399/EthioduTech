<Context>
Now that we have a skeleton, let's add content. Text shouldn't just be dumped into the body—it needs to be structured so both humans and search engines understand it.
</Context>

<Objective>
By the end of this lesson, you will format text content using appropriate heading hierarchies and paragraph tags.
</Objective>

<Concept>
## Semantics: Headings and Paragraphs
- **Headings (`<h1>` to `<h6>`)**: Used for titles and subtitles. `<h1>` is the most important (the main title).
- **Paragraphs (`<p>`)**: Used for blocks of standard text.

*Important:* Never use a heading just to make text bold or big. Use headings to outline your document's structure, like chapters in a book.
</Concept>

<InteractiveSandbox type="classification">
If you are writing an article about "Space Exploration", and you have a sub-section titled "The Apollo Missions", which heading tag should you use for the sub-section?
</InteractiveSandbox>

<Feedback>
You should use `<h2>`. The main title of the page ("Space Exploration") should be the `<h1>`.
</Feedback>
