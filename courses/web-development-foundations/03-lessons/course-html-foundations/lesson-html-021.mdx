<Context>
It is time to put everything together. You are going to build a completely functional, multi-page Recipe Website.
</Context>

<Objective>
By the end of this lesson, you will synthesize HTML tags, semantics, paths, and forms to build a fully linked multi-page website.
</Objective>

<Concept>
## The Build Process
You will build a two-page site:
1. **`index.html`**: The homepage. It should have a semantic `<header>`, a `<nav>` linking to the contact page, and a `<main>` section listing your favorite recipes using an Unordered List (`<ul>`).
2. **`contact.html`**: A contact page. It should have a navigation link back to the homepage, and a simple `<form>` with a properly labeled text input and submit button.
</Concept>

<InteractiveSandbox type="implementation">
Build `index.html` and `contact.html`. Ensure all images have alt text, all forms have linked labels, and the site uses semantic landmarks.
</InteractiveSandbox>

<HintLadder>
- Level 1: Start with the HTML Skeleton (`<!DOCTYPE>`) for both files.
- Level 2: Add a `<nav>` to both files. `index.html` links to `contact.html`, and vice versa.
- Level 3: Inside `index.html`, use a `<ul>` and `<li>` for the recipes.
- Level 4: Inside `contact.html`, create a `<form>` with a `<label for="name">` and `<input id="name">`.
</HintLadder>

<Reflection>
Congratulations! You have transitioned from writing isolated tags to architecting a complete, accessible, semantic web project. You are officially ready to learn how to style these pages with CSS!
</Reflection>
