<Context>
You know how to write a URL. Now, what actually happens when you hit "Enter"?
</Context>

<Objective>
By the end of this lesson, you will be able to explain the URL request and response cycle, identifying the roles of the DNS, server, and browser.
</Objective>

<Concept>
## The Request / Response Cycle
When you type a URL, your browser acts as a messenger:
1. **The Request**: Your browser asks the internet, "Where is this domain?" (Using DNS, which is like a phonebook).
2. **The Server**: The computer that owns the domain receives the request and gathers the files.
3. **The Response**: The server sends the HTML, CSS, and JavaScript files back to your browser.
4. **Rendering**: Your browser processes those files and paints the webpage on your screen.
</Concept>

<InteractiveSandbox type="ordering">
Order the steps of fetching a webpage:
- Server sends files back
- Browser renders the page
- User types URL
- Browser finds the server via DNS
</InteractiveSandbox>

<Reflection>
Think of the browser as a customer at a restaurant, the request as the order, and the server as the kitchen. You ask for a page, the server prepares it, and the browser serves it to you visually!
</Reflection>
