<Context>
Welcome to web development! Before we dive into the deep end of how the internet works, we are going to do something very simple: create a webpage and view it on your own computer.
</Context>

<Objective>
By the end of this lesson, you will be able to open a local HTML file in a web browser and see the result.
</Objective>

<Concept>
## What is an HTML file?
A webpage is essentially just a text document that your browser knows how to read. You don't need a live server to view it—you can just open a file from your hard drive.
</Concept>

<GuidedPractice>
## Let's do it together
1. Create a new file on your computer and name it `index.html`.
2. Type the following text into the file:
   `<h1>Hello World!</h1>`
3. Save the file.
4. Drag and drop the file directly into your web browser (like Chrome or Firefox).

You should see the words **Hello World!** displayed as a large heading.
</GuidedPractice>

<IndependentPractice>
## Now it's your turn
Change the text inside the `<h1>` tags to your own name. Save the file, and refresh your browser.
</IndependentPractice>

<Reflection>
You've just built and viewed your first webpage! Notice that you didn't need the internet to do this. Your browser simply read the text file from your computer and rendered it visually.
</Reflection>
