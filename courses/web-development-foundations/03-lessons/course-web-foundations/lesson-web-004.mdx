<Context>
The server sends back files, but what exactly are those files doing? The web is built on three core languages that work together.
</Context>

<Objective>
By the end of this lesson, you will be able to identify whether HTML, CSS, or JavaScript is responsible for a given structural, visual, or behavioral web feature.
</Objective>

<Concept>
## The Three Pillars of the Web
1. **HTML (Structure)**: The nouns. It defines the content (headings, paragraphs, images).
2. **CSS (Presentation)**: The adjectives. It defines how things look (colors, layouts, fonts).
3. **JavaScript (Behavior)**: The verbs. It defines what things do (clicking a button, fetching new data).
</Concept>

<InteractiveSandbox type="classification">
Classify the following feature: "A button turns blue when you hover over it."
Is this HTML, CSS, or JavaScript?
</InteractiveSandbox>

<HintLadder>
- Level 1: Does this define the button's existence, its look, or complex logic?
- Level 2: Changing colors visually is presentation.
- Level 3: This is CSS.
</HintLadder>

<IndependentPractice>
Categorize the following:
1. A paragraph of text. (HTML)
2. A popup that appears when a timer hits zero. (JavaScript)
3. Making an image circular. (CSS)
</IndependentPractice>
