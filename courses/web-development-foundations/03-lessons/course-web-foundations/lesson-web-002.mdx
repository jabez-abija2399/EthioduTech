<Context>
In the previous lesson, you opened a file directly from your computer. But when you visit a website online, you type an address into the browser. This address is called a URL.
</Context>

<Objective>
By the end of this lesson, you will be able to identify the scheme, domain, and path of a given URL.
</Objective>

<Concept>
## The Anatomy of a URL
A URL (Uniform Resource Locator) is a specific type of address. Let's break down a common URL:
`https://www.example.com/about`

1. **Scheme**: `https://` tells the browser *how* to connect (securely).
2. **Domain**: `www.example.com` tells the browser *who* you are trying to reach (the specific server).
3. **Path**: `/about` tells the server *what* specific page or file you want.
</Concept>
