<Context>
In the last lesson, you learned how to look at the code behind a page. Now, let's learn how to change it.
</Context>

<Objective>
By the end of this lesson, you will temporarily modify styles and text on a live page using Developer Tools.
</Objective>

<Concept>
## Live Editing
DevTools doesn't just read code; it lets you edit it. However, these edits only exist on your own computer. When you refresh the page, the browser fetches the original files from the server again, wiping out your changes.
</Concept>

<GuidedPractice>
## Hack the Web
1. Right-click a paragraph of text on this page and click **"Inspect"**.
2. In the Elements panel, double-click the text inside the HTML tags.
3. Type something new and press Enter. The live page will update!
</GuidedPractice>

<IndependentPractice>
1. Inspect an element.
2. Look at the **"Styles"** pane next to the HTML.
3. In the "Styles" pane, click inside the block for `element.style` (or an existing rule) and type `color: red;`. Press Enter to see the text turn red.
</IndependentPractice>

<Reflection>
You've just manipulated the live DOM! This is how developers rapidly test layout fixes and debug visual issues before permanently saving code to their files.
</Reflection>
