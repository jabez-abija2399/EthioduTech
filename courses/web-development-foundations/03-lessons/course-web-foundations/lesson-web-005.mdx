<Context>
Your browser isn't just a viewer—it's a powerful developer environment. All modern browsers come with Developer Tools built right in.
</Context>

<Objective>
By the end of this lesson, you will use browser developer tools to inspect DOM elements.
</Objective>

<Concept>
## What are Developer Tools?
Developer Tools (DevTools) let you peek behind the curtain of any webpage to see the exact HTML and CSS the browser is currently rendering.
</Concept>

<GuidedPractice>
## Let's Inspect!
1. Right-click anywhere on this webpage.
2. Select **"Inspect"** or **"Inspect Element"** from the menu.
3. A panel will open. Ensure you are on the **"Elements"** tab.
4. Hover your mouse over the lines of HTML in the panel. Notice how different parts of the page light up.
</GuidedPractice>

<IndependentPractice>
Find the HTML element that controls the main heading of this page using the Inspector.
</IndependentPractice>

<Reflection>
You can inspect *any* website on the internet this way! Go to your favorite site and see how it's built under the hood.
</Reflection>
