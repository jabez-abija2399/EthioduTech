## Known Limitations
* Branching and merging (`git branch`, `git merge`) are omitted to reduce cognitive load; the course focuses exclusively on a linear `main` branch history.
* Accessibility testing currently relies on manual alt-text review rather than automated axe-core tools, as students have not yet learned how to install npm dependencies.
