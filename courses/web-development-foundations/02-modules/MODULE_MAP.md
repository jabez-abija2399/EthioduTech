# MODULE MAP: Vertical Slice (Phases 0, 1, and HTML Module 1)

This map defines the sequence of modules and lessons for the vertical slice of the Web Development Foundations course.

## PHASE 0: GETTING STARTED
**Goal:** The learner can independently create files, edit code, and view their work in a browser using standard developer tools.

- **`ENV-L01`: Your Developer Workspace**
  - Connects to: `SKILL-ENV-01`
  - Concepts: Terminal vs GUI, directories, `mkdir`, `cd`, `touch`.
- **`ENV-L02`: Writing and Running Code**
  - Connects to: `SKILL-ENV-02`
  - Concepts: IDE interface, opening folders, writing basic text, running a local HTTP server, Chrome DevTools Elements tab.

## PHASE 1: WEB FOUNDATIONS
**Goal:** The learner understands the physical and logical architecture of the web to correctly isolate bugs in the future.

- **`WEB-L01`: How the Web Works**
  - Connects to: `SKILL-WEB-01`
  - Concepts: Client, Server, IP, DNS, HTTP Request/Response cycle.
- **`WEB-L02`: The Frontend Trinity**
  - Connects to: `SKILL-WEB-02`
  - Concepts: Structure (HTML), Presentation (CSS), Behavior (JS).

## PHASE 2: HTML FUNDAMENTALS (Module 1)
**Goal:** The learner can author a well-structured, multi-page, text-based website using semantic HTML and hyperlinking.

- **`HTML-L01`: The HTML Boilerplate**
  - Connects to: `SKILL-HTML-01`
  - Concepts: Document type, head, body, meta tags, the concept of nested tags.
- **`HTML-L02`: Structuring Text**
  - Connects to: `SKILL-HTML-02`
  - Concepts: Headings, paragraphs, strong/em, unordered and ordered lists.
- **`HTML-L03`: Links and Images**
  - Connects to: `SKILL-HTML-03`
  - Concepts: Absolute vs relative URLs, `<a>` tags, `<img>` tags, `alt` text and accessibility.

## CAPSTONE FOR VERTICAL SLICE
- **`PROJECT-HTML-M1`: The Personal Knowledge Base**
  - A 3-page purely HTML website (no CSS) linking to notes, lists, and images, fully semantic.

## PHASE 3: CSS FUNDAMENTALS (Module 2)
**Goal:** The learner can separate presentation from structure, visually debug layout issues, and build a responsive landing page.

- **`CSS-L01`: Selectors and Properties**
  - Connects to: `SKILL-CSS-01`
  - Concepts: Connecting a `.css` file, tag/class/ID selectors, colors, typography.
- **`CSS-L02`: The Box Model**
  - Connects to: `SKILL-CSS-02`
  - Concepts: Width, height, padding, border, margin. Inspecting the Box Model in DevTools.
- **`CSS-L03`: Flexbox Layout**
  - Connects to: `SKILL-CSS-03`
  - Concepts: `display: flex`, flex direction, justification, alignment.

## PHASE 4: JAVASCRIPT FUNDAMENTALS (Module 3)
**Goal:** The learner can store data, read the DOM, and react to user events to make a page interactive.

- **`JS-L01`: Variables and Data**
  - Connects to: `SKILL-JS-01`
  - Concepts: Connecting a `.js` file, `console.log`, `let` vs `const`, strings, numbers.
- **`JS-L02`: DOM Manipulation**
  - Connects to: `SKILL-JS-02`
  - Concepts: `document.querySelector`, `.textContent`, `.style`, reading input values.
- **`JS-L03`: Event Handling**
  - Connects to: `SKILL-JS-03`
  - Concepts: `addEventListener`, click events, function references vs invocations.

## PHASE 5: VERSION CONTROL (Module 4)
**Goal:** The learner can save snapshots of their code history and back them up to a remote server.

- **`GIT-L01`: Local Version Control**
  - Connects to: `SKILL-GIT-01`
  - Concepts: `git init`, `git add`, `git commit -m`. The concept of a local repository.
- **`GIT-L02`: Remote Repositories**
  - Connects to: `SKILL-GIT-02`
  - Concepts: GitHub vs Git, pushing code, viewing repositories online.

## PHASE 6: FINAL CAPSTONE (Module 5)
**Goal:** The learner can synthesize everything they have learned to build and deploy a real-world project from an empty folder to a live URL.

- **`CAP-L01`: The Interactive Portfolio**
  - Connects to: `SKILL-CAP-01`
  - Concepts: Project planning, breaking down UI into components, combining HTML/CSS/JS, deploying via GitHub Pages.
