# Competitor Review

## Codecademy
- **Audience:** Self-directed adult/young adult learners.
- **Learning-path structure:** Highly structured paths (e.g., "Front-End Engineer") containing multiple nested courses.
- **Course structure:** Module -> Lesson -> Interactive Exercise.
- **Lesson structure:** Short reading on left pane, code editor in center, browser rendering on right pane.
- **Practice:** Immediate syntax practice in sandbox.
- **Assessment:** Multiple choice quizzes and project challenges.
- **Project model:** Guided projects (step-by-step) and portfolio projects (independent).
- **Progression:** Linear progression, locked until completion.
- **Personalization:** Pro version offers customized practice.
- **Strengths:** Excellent micro-interactions; the feedback loop is very tight.
- **Limitations:** "Tutorial hell" — learners often struggle to build locally after leaving the web sandbox.
- **What this product should learn from it:** The value of immediate interactive feedback and clear path structure.
- **What this product should deliberately do differently:** We must force local/independent development (via the Capstone and Git course) so learners don't get trapped in the sandbox.

## Harvard CS50 Web (CS50W)
- **Audience:** University students and highly motivated independent learners.
- **Learning-path structure:** Sequential lectures followed by massive problem sets.
- **Course structure:** Weekly massive lectures (2+ hours).
- **Lesson structure:** Video lecture + extensive reading notes.
- **Practice:** Sparse guided practice; heavy emphasis on problem sets.
- **Assessment:** Automated testing on GitHub.
- **Project model:** Completely independent application development based on a spec.
- **Progression:** Strict weekly progression.
- **Personalization:** None.
- **Strengths:** Produces highly capable, independent developers.
- **Limitations:** Extremely steep learning curve; high drop-out rate for true beginners.
- **What this product should learn from it:** The necessity of rigorous, portfolio-worthy final projects.
- **What this product should deliberately do differently:** We must scaffold much more gently than CS50.

## Code.org CS Discoveries
- **Audience:** Middle school / High school (Grades 6-10).
- **Learning-path structure:** Modular units that can be taught independently or as a full year.
- **Course structure:** Lesson plans with plugged and unplugged activities.
- **Lesson structure:** Step-by-step bubble progression.
- **Practice:** Highly scaffolded block-to-text practice.
- **Assessment:** Formative checks for understanding.
- **Project model:** Creative, expressive micro-projects.
- **Progression:** Extremely granular step-by-step.
- **Personalization:** Teacher-led pacing.
- **Strengths:** Incredible accessibility; prevents beginner frustration.
- **Limitations:** Can feel toy-like; doesn't transition to professional tools quickly enough.
- **What this product should learn from it:** The importance of immediate visual wins and preventing cognitive overload in the very first course.
- **What this product should deliberately do differently:** We must transition the learner to professional tools (VS Code, Terminal, Git) earlier than Code.org does.
