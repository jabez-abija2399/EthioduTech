# Curriculum Map

This is the human-readable master overview of the Web Development Foundations learning path.

**Total Target Workload:** ~84 Hours
**Total Courses:** 6
**Total Modules:** 49

---

## Course 1: Web Foundations (5 Hours)
**Target:** Build a first webpage and understand the underlying request/response cycle.
- **MOD-WEB-01:** First Contact With the Web (1.0h)
- **MOD-WEB-02:** How the Web Works (1.5h)
- **MOD-WEB-03:** HTML, CSS and JavaScript Together (1.0h)
- **MOD-WEB-04:** Developer Environment and Browser Tools (1.5h)
**Major Projects:** First Webpage
**Assessments:** Diagnostic mapping, Concept recognition

## Course 2: HTML Foundations (12 Hours)
**Target:** Structure content semantically and accessibly.
**Prerequisite:** Course 1
- **MOD-HTML-01 to 04:** Structure, Text, Links, Media
- **MOD-HTML-05:** Semantic Structure (1.5h)
- **MOD-HTML-06 to 08:** Tables, Forms, Accessibility
- **MOD-HTML-09:** Multi-Page Website Project (1.5h)
**Major Projects:** Multi-Page Semantic Site
**Assessments:** Code completion (semantics), Accessibility Audits

## Course 3: CSS Foundations (16 Hours)
**Target:** Build responsive layouts and accessible visual hierarchies.
**Prerequisite:** Course 2
- **MOD-CSS-01 to 02:** Mental Model, Selectors, Typography
- **MOD-CSS-03 to 04:** Box Model, Positioning
- **MOD-CSS-05 to 06:** Flexbox, Grid
- **MOD-CSS-07 to 08:** Responsive Design, Accessibility
- **MOD-CSS-09:** Responsive Interface Project (1.5h)
**Major Projects:** Responsive Interface (Mobile-First)
**Assessments:** Visual debugging, Layout challenges

## Course 4: JavaScript Foundations (26 Hours)
**Target:** Add logic, manage state, manipulate the DOM, and fetch data.
**Prerequisite:** Course 2 and Course 3
- **MOD-JS-01 to 05:** Logic, Variables, Conditions, Loops
- **MOD-JS-06 to 08:** Functions, Arrays, Objects
- **MOD-JS-09:** Debugging (2.0h)
- **MOD-JS-10 to 11:** DOM, Events, Forms, State
- **MOD-JS-12 to 13:** Local Storage, Async & APIs
- **MOD-JS-14:** Integration Project (2.0h)
**Major Projects:** API-Integrated Application
**Assessments:** Algorithmic logic puzzles, Bug fixing, DOM manipulation practicals

## Course 5: Git & GitHub for Web Developers (7 Hours)
**Target:** Use version control to track history and collaborate.
**Prerequisite:** Course 4
- **MOD-GIT-01 to 03:** Version Control, Local Workflow, History
- **MOD-GIT-04 to 06:** Branches, Remotes, Collaboration
**Major Projects:** Documented GitHub Repository
**Assessments:** Git sequence commands, PR reviews

## Course 6: Web Development Capstone (18 Hours)
**Target:** Independently plan, design, and build a full web application.
**Prerequisite:** Courses 1-5
- **MOD-CAP-01 to 02:** Problem, Audience, Planning
- **MOD-CAP-03 to 04:** HTML/CSS Build, JS Build
- **MOD-CAP-05:** Testing & Accessibility
- **MOD-CAP-06 to 07:** Git, Docs, Presentation
**Major Projects:** Final Independent Capstone
**Assessments:** Comprehensive project audit, Rubric review
