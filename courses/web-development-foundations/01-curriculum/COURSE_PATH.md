# COURSE PATH: Web Development Foundations

## Identity
- **Path ID:** `path-web-dev-foundations`
- **Title:** Web Development Foundations
- **Description:** A beginner-friendly, highly scaffolded introduction to the modern web, covering structure (HTML), presentation (CSS), logic (JavaScript), and professional version control (Git/GitHub), culminating in a portfolio-ready Capstone project.
- **Target Learner:** Beginners (Grades 5-12 in Ethiopia, and global learners).
- **Level:** Absolute Beginner

## Entry Point
- Basic computer literacy (using a mouse/keyboard, installing software).
- Basic web familiarity (knowing how to use a web browser and search engine).
- No prior programming experience required.

## End Capability
- Independently plan, build, debug, document, version, and publish a small interactive web application.

## Course Sequence
1. **Course 01 — Web Foundations (`course-web-foundations`)**: Establishes the mental model of the web before syntax.
2. **Course 02 — HTML Foundations (`course-html-foundations`)**: Focuses purely on semantic document structure.
3. **Course 03 — CSS Foundations (`course-css-foundations`)**: Teaches presentation and layout. Depends on HTML knowledge.
4. **Course 04 — JavaScript Foundations (`course-js-foundations`)**: Introduces programming logic and browser APIs. Depends on HTML/CSS.
5. **Course 05 — Git & GitHub (`course-git-github`)**: Formalizes version control. Students have already practiced `commit` in Courses 2-4, but this teaches branching and collaboration.
6. **Course 06 — Capstone (`course-web-capstone`)**: Synthesizes all previous courses into independent application creation.

## Dependencies

### Course 01
- **Prerequisites:** None
- **Dependencies:** None
- **Expected prior capabilities:** Basic computer use.
- **Outputs required by next course:** Mental model of client/server, files, and browsers.

### Course 02
- **Prerequisites:** Completion of Course 01
- **Dependencies:** `course-web-foundations`
- **Expected prior capabilities:** Understanding of files/folders.
- **Outputs required by next course:** Semantic HTML document creation.

### Course 03
- **Prerequisites:** HTML structure
- **Dependencies:** `course-html-foundations`
- **Expected prior capabilities:** Can write standard HTML tags.
- **Outputs required by next course:** Ability to style elements and manage layout, used heavily when building JS interfaces.

### Course 04
- **Prerequisites:** HTML & CSS
- **Dependencies:** `course-html-foundations`, `course-css-foundations`
- **Expected prior capabilities:** Can build a static responsive webpage.
- **Outputs required by next course:** Basic programming capability to build functional logic.

### Course 05
- **Prerequisites:** Basic Git commit muscle memory from Courses 2-4
- **Dependencies:** `course-js-foundations`
- **Expected prior capabilities:** Can build a JS application locally.
- **Outputs required by next course:** A GitHub repository ready to host the capstone.

### Course 06
- **Prerequisites:** All previous courses
- **Dependencies:** `course-git-github`
- **Expected prior capabilities:** HTML, CSS, JS, Git.
- **Outputs required by next course:** Portfolio artifact.

## Progression
web understanding → semantic structure → styling/layout → programming → version control → independent creation

## Project Progression
Micro Project (Course 1) → Guided Project (Course 2) → Module Project (Course 3) → Independent Project (Course 4) → Capstone (Course 6)

## Portfolio Progression
First webpage → Multi-page HTML site → Responsive website → Interactive application → API-powered application → Documented GitHub repository → Independent capstone

After completing this path, the learner will have the capability to enter modern front-end frameworks (React, Next.js, TypeScript).
