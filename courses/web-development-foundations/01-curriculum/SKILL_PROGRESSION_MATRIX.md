# Skill Progression Matrix

This document tracks the learning arc for the critical capabilities in the curriculum. Every durable skill progresses from introduction to mastery.

## Skill Arc Definitions
- **Introduce:** First explicit teaching of the skill.
- **Practice:** First guided repetition (We Do / You Do With Support).
- **Retrieve:** Recalling the skill from memory in a later lesson/module.
- **Apply:** Using the skill in a new context or small project.
- **Assess:** Formal verification of the skill.
- **Reapply:** Using the skill in a later course or larger context.
- **Master:** Final, unguided verification (e.g., Capstone).
