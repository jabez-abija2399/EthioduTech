# Concept Graph

This document maps all major concepts in the curriculum to the explicit skills they support. A concept that does not support a skill is flagged as orphaned and removed.

## Course 1: Web Foundations

### Concept: Client/Server Model (con-web-01)
- **Related Concepts:** URL, HTTP Request/Response, DNS
- **Skills Supported:** `skill-web-network` (Explain a simple page-loading journey)
- **Module:** mod-web-02

### Concept: HTML/CSS/JS Roles (con-web-02)
- **Related Concepts:** Webpage, Browser rendering
- **Skills Supported:** `skill-web-roles` (Distinguish which technology solves a given UI problem)
- **Module:** mod-web-03
