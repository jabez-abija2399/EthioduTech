# Retrieval Spiral

This document maps the deliberate interleaving and retrieval of durable, high-value skills across the learning path. This ensures that critical knowledge does not decay before the capstone.

## 1. Semantic HTML & Document Structure
- **First Introduction:** HTML-05 (Semantic Structure)
- **Initial Practice:** HTML-05 (Replacing `div` tags with `<header>`, `<main>`, `<article>`)
- **Retrieval Opportunities:** 
  - HTML-08 (Accessibility Review) requires recalling semantic meaning.
  - CSS-01 requires recalling tags to write element selectors.
- **Reapplication Contexts:** 
  - CSS-09 (Responsive Interface Project) requires structuring the HTML before styling it.
  - JS-10 (DOM Interaction) requires targeting semantic elements.
- **Assessment:** HTML-09 Project Automated Validation.
- **Later Project Use:** Required in JS-14 Integration Project.
- **Mastery Evidence:** CAP-03 (Capstone HTML Build).

## 2. Accessibility (A11y)
- **First Introduction:** HTML-08 (Accessibility & Document Quality)
- **Initial Practice:** HTML-08 (Fixing missing alt text, form labels, and heading hierarchy)
- **Retrieval Opportunities:** 
  - CSS-02 (Color & Typography) requires recalling contrast rules.
  - CSS-08 (Accessibility and Design) requires recalling focus states and readability.
- **Reapplication Contexts:** 
  - JS-11 (Events & Forms) requires ensuring dynamic state changes are accessible (e.g., ARIA or simple focus management).
- **Assessment:** CSS-09 Project Rubric (Contrast & Focus checks).
- **Later Project Use:** JS-14 (Integration Project).
- **Mastery Evidence:** CAP-05 (Testing, Debugging & Accessibility Audit).

## 3. CSS Layouts (Flexbox & Grid)
- **First Introduction:** CSS-05 (Flexbox) and CSS-06 (Grid)
- **Initial Practice:** Isolated layout challenges (e.g., aligning nav items, building a card grid).
- **Retrieval Opportunities:** 
  - CSS-07 (Responsive Design) requires modifying Flex/Grid behavior in media queries.
- **Reapplication Contexts:** 
  - JS-14 (Integration Project) requires building the application UI using Flex/Grid before wiring up the JS.
- **Assessment:** CSS-09 Responsive Interface Project.
- **Later Project Use:** Capstone UI development.
- **Mastery Evidence:** CAP-03 (Capstone CSS Build).

## 4. Debugging & Error Isolation
- **First Introduction:** JS-09 (Debugging and Program Investigation)
- **Initial Practice:** Finding syntax and logic errors in intentionally broken code snippets using Chrome DevTools.
- **Retrieval Opportunities:** 
  - JS-10 (DOM) - Diagnosing `null` selector returns.
  - JS-13 (Async & APIs) - Diagnosing network `404` or JSON parsing errors.
- **Reapplication Contexts:** 
  - GIT-03 (History & Recovery) - Debugging Git state (e.g., detached HEAD).
- **Assessment:** JS-09 Debugging Challenge.
- **Later Project Use:** Required to complete JS-14 and Capstone independently.
- **Mastery Evidence:** CAP-05 (Explicit debugging phase of Capstone).

## 5. Arrays, Objects & Data iteration
- **First Introduction:** JS-07 (Strings and Arrays) & JS-08 (Objects and Data Modeling)
- **Initial Practice:** Iterating over arrays of strings/numbers; accessing object properties.
- **Retrieval Opportunities:** 
  - JS-10 (DOM) - Iterating over `querySelectorAll` NodeLists.
- **Reapplication Contexts:** 
  - JS-12 (Local Storage) - Serializing/deserializing arrays of objects.
  - JS-13 (Async & APIs) - Iterating over API JSON response data to render UI cards.
- **Assessment:** JS-07 and JS-08 Coding Challenges.
- **Later Project Use:** JS-14 (Integration Project - managing application state).
- **Mastery Evidence:** CAP-04 (Capstone JavaScript Build).
