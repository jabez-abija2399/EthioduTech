# Traceability Matrix

This matrix ensures that no learning outcome is orphaned and that every required capability is explicitly taught, practiced, and assessed. 

| Course Outcome | Skill | Module | Planned Lesson Scope | Practice / Evidence | Assessment | Project | Mastery Evidence |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| `OUT-WEB-01` (Explain Web) | `SKILL-WEB-NETWORK` | `WEB-02` | How browsers request pages | Sketch request cycle | `ASSESS-WEB-02` (Explanation) | First Webpage | Verbally or textually explains the DNS/Server/Browser path without syntax. |
| `OUT-HTML-01` (Structure) | `SKILL-HTML-SEMANTIC` | `HTML-05` | Using `<header>`, `<main>`, `<article>` | Wrap raw text in semantic tags | `ASSESS-HTML-05` (Code Completion) | HTML-09 Multi-page Site | Passes automated DOM tree check for semantic tags. |
| `OUT-HTML-02` (A11y) | `SKILL-HTML-A11Y` | `HTML-08` | Forms, Alt Text, and Focus | Audit broken page | `ASSESS-HTML-08` (Debugging) | HTML-09 Multi-page Site | Validates against HTML checker and Lighthouse. |
| `OUT-CSS-01` (Layout) | `SKILL-CSS-FLEX` | `CSS-05` | Flex container, alignment, gap | Align items in a header | `ASSESS-CSS-05` (Coding Challenge) | CSS-09 Responsive Site | Responsive layout matches target screenshot at all breakpoints. |
| `OUT-JS-01` (Logic) | `SKILL-JS-FUNC` | `JS-06` | Parameters, return values, scope | Write simple math functions | `ASSESS-JS-06` (Coding Challenge) | JS-14 Integration Project | Creates pure functions without side effects. |
| `OUT-JS-02` (Behavior) | `SKILL-JS-DOM` | `JS-10` | Selectors and properties | Toggle a CSS class on click | `ASSESS-JS-10` (Practical Task) | JS-14 Integration Project | UI dynamically reflects JS state changes. |
| `OUT-JS-03` (Data) | `SKILL-JS-ASYNC` | `JS-13` | Fetch, JSON, Loading states | Request API and log data | `ASSESS-JS-13` (Code Completion) | JS-14 Integration Project | Successfully handles Promises, rendering data and catching errors. |
| `OUT-GIT-01` (Version) | `SKILL-GIT-WORKFLOW` | `GIT-06` | Branches, merges, and remotes | Resolve a merge conflict | `ASSESS-GIT-06` (Practical Task) | Capstone Repo | Verifiable GitHub repository with branch/PR history. |
| `OUT-CAP-01` (Build) | `All Skills` | `CAP-01` to `CAP-07` | Project definition to presentation | Independent building | Capstone Audit | Web Dev Capstone | Live deployed application with public code repository and passing rubric. |
