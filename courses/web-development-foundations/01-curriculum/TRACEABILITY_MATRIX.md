# Traceability Matrix

This matrix ensures that no learning outcome is orphaned and that every required capability is explicitly taught, practiced, and assessed.

| Outcome ID | Skill ID | Module ID | Planned Lesson Scope | Assessment ID | Project ID | Mastery Evidence |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| `out-web-01` | `skill-url-anatomy`, `skill-http-basics` | `mod-web-01` | How browsers request pages | `assess-web-diag` | `proj-first-page` | Student successfully explains the request/response cycle verbally or via a reflection prompt. |
| `out-html-01` | `skill-html-tags`, `skill-semantic-markup` | `mod-html-03` | Building accessible document skeletons | `assess-html-sem` | `proj-recipe-site` | Student creates a multi-page HTML site using `<header>`, `<nav>`, `<main>`, `<article>`, and `<footer>` correctly. |
| `out-css-01` | `skill-css-selectors`, `skill-box-model`, `skill-flexbox`, `skill-media-queries` | `mod-css-03`, `mod-css-04` | Layouts with Flexbox & Media Queries | `assess-css-layout` | `proj-portfolio-grid` | Student implements a responsive photo gallery grid that collapses to a single column on mobile screens without hardcoded pixel widths. |
| `out-js-01` | `skill-js-variables`, `skill-js-functions`, `skill-dom-selection`, `skill-event-listeners` | `mod-js-04`, `mod-js-05` | Selecting DOM elements and attaching event listeners | `assess-js-dom` | `proj-weather-app` (UI Part) | Student writes a JS function that changes the color of a button when clicked, verifying state changes in DevTools. |
| `out-js-02` | `skill-fetch-api` | `mod-js-06` | Making async fetch requests and parsing JSON | `assess-js-dom` | `proj-weather-app` (Data Part) | Student fetches live weather data from a free API, handles the promise, and injects the JSON text into the DOM. |
| `out-git-01` | `skill-git-commit`, `skill-git-branch`, `skill-github-pr` | `mod-git-02`, `mod-git-03` | Creating branches, resolving conflicts, and opening PRs | `assess-git-flow` | `proj-capstone` | Student successfully opens a Pull Request on GitHub with a descriptive commit history. |
| `out-cap-01` | All skills | `mod-cap-01` to `mod-cap-03` | Planning, Building, Testing | N/A (Project is the assessment) | `proj-capstone` | Student publishes a live, fully functional web application on Vercel/GitHub Pages with a documented README. |
