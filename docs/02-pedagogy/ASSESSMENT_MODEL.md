# ASSESSMENT MODEL — EDUTECH PLATFORM

## 1. Multi-Dimensional Assessment Strategy

The platform deliberately avoids relying solely on simple multiple-choice quizzes. Assessment consists of:

```text
1. Practical Code Exercises (Auto-checked syntax & output)
2. Interactive Code Challenges (Unassisted problem solving)
3. Project Reflections (Student written explanation of how their code works)
4. Portfolio Demonstrations (Live rendered working web application)
5. AI Socratic Checks (Student explaining logic to AI Tutor)
```

## 2. Assessment Types & Criteria

| Assessment Type | Format | Evaluation Method | Weight in Mastery |
| :--- | :--- | :--- | :--- |
| **Guided Exercise** | Code Sandbox | Live iframe execution check | 20% |
| **Unassisted Challenge** | Code Sandbox | Output validation & DOM tests | 30% |
| **Project Artifact** | Full Sandbox | Portfolio publishing & live preview | 40% |
| **Written Reflection** | Text Prompt | AI / Teacher qualitative review | 10% |
