# MVP Scope: Web Creator Foundations

## MVP Goal
The singular objective of the Minimum Viable Product (MVP) is to prove one hypothesis: **CAN STUDENTS ACTUALLY LEARN AND BUILD THROUGH THIS SYSTEM?**

## The Target Course
We will focus on implementing a single, complete learning experience: **"Web Creator Foundations"** (Grades 7-8 equivalent). 

## Core Features Required for MVP
1. **User Accounts:** Registration with age/grade selection.
2. **Diagnostic Assessment:** A brief initial assessment to place the student.
3. **Course Dashboard:** To track progress through the Web Creator course.
4. **Lesson Delivery System:** Delivering concepts via text, images, and interactive snippets (no heavy video).
5. **Browser Code Editor:** A safe, sandboxed environment for writing and running HTML/CSS/JS.
6. **Interactive Exercises:** Small practice tasks following each concept.
7. **Coding Challenges:** Independent problems without step-by-step guidance.
8. **Project Progression:** Breaking a larger project down feature-by-feature.
9. **Basic Git-Style History:** The ability to "save" versions of code and revert.
10. **AI Tutor:** A restricted assistant that provides hints and asks Socratic questions.
11. **Assessments & Mastery Tracking:** Formal checks before allowing progression.
12. **Project Portfolio:** A public-facing page showcasing the student's final built project.
13. **Safety & Moderation:** Basic controls for parents to monitor activity.
14. **PWA/Offline Foundation:** The architecture must support low-bandwidth resilience from day one.
