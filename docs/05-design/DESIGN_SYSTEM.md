# DESIGN SYSTEM & STYLING ARCHITECTURE

## 1. Palette & Typography
- **Primary Accent:** Slate Blue (`#2563eb`) & Emerald (`#059669`).
- **Dark Mode IDE Canvas:** Slate 950 (`#020617`), Slate 900 (`#0f172a`), Slate 800 (`#1e293b`).
- **Typography:** Sans-serif Geist / system font stack with high contrast ratio (minimum 4.5:1 for WCAG AA compliance).

## 2. Aesthetic Principles
- **Glassmorphism & Micro-animations:** Subtle backdrop blurs (`backdrop-blur-md`), smooth border transitions (`transition-all duration-300`).
- **Clean Spatial Hierarchy:** Explicit padding (`p-6`, `gap-4`) and rounded corners (`rounded-2xl`).
- **Pills & Badges:** Compact status tags for roles, XP points, and daily streaks.
