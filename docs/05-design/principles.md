# Design Principles

## Core Aesthetic
The UI must be **modern, friendly, simple, and professional.** It should evoke the feeling of "learning + building + progress."

## What We Must Avoid
- **Enterprise HR Software:** It should not be drab, overly complex, or dense with data tables.
- **University Administration:** It should not feel bureaucratic or old-fashioned.
- **Social Media:** It should not optimize for endless scrolling or addictive loops.

## Key Design Directives

### 1. Mobile-First & Responsive
The majority of our initial users (especially in Ethiopia) will access the platform via smartphones. Every component, including the code editor and project viewer, must have a thoughtful mobile layout.

### 2. Low-Bandwidth Aware
- Use system fonts or highly optimized web fonts.
- Avoid large, unoptimized background images or autoplaying videos.
- Use SVGs for icons and illustrations.
- Provide clear loading states and offline indicators (PWA).

### 3. Accessible
- High contrast text.
- Clear, descriptive buttons (no mystery meat navigation).
- Support for screen readers and keyboard navigation where applicable.

### 4. Focused Learning
- Remove distractions from the learning interface.
- Use progressive disclosure (only show information when it is needed).
- Provide frequent, small bursts of positive reinforcement when students complete challenges.
