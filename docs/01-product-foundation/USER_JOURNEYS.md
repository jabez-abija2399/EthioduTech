# USER JOURNEYS — EDUTECH PLATFORM

## 1. Student Journey: From Zero to Web Creator

```text
SIGNUP / LOGIN
  ↓
SELECT COURSE ("Web Creator Foundations")
  ↓
READ LESSON (Markdown Content & Concept Explanation)
  ↓
WRITE CODE (HTML / CSS / JS in Multi-Tab Editor)
  ↓
LIVE PREVIEW (Instant Sandboxed <iframe> Feedback)
  ↓
ASK AI TUTOR (Get Hints / Debug Assistance if Stuck)
  ↓
COMPLETE LESSON (+50 XP, Streak 🔥 Increment)
  ↓
PUBLISH TO PORTFOLIO (1-Click Publish Modal)
  ↓
SHARE PUBLIC SHOWCASE (/portfolio/[studentId])
```
