# PRODUCT SPECIFICATION — EDUTECH PLATFORM

## 1. Executive Summary
The **Edutech Platform** is an Ethiopian-first, low-bandwidth, project-based learning system designed to teach Grades 5–12 students practical software development and creative computing skills.

## 2. Core Value Proposition
- **Project-Based Learning:** Every lesson leads to an interactive web project.
- **Offline-First PWA:** Works seamlessly under low-bandwidth, intermittent, or offline conditions.
- **In-Browser Sandbox:** Multi-tab HTML/CSS/JS editor with instant sandboxed live output.
- **Socratic AI Tutor:** Embedded assistant providing hints and bug guidance without spoiling answers.
- **Gamified Progress:** Daily learning streaks, XP points, and unlocked badge achievements.
- **Shareable Portfolios:** Public showcase URL (`/portfolio/[studentId]`) displaying live project previews.

## 3. Supported User Roles
1. **Student:** Enrolls in courses, writes code, builds projects, earns XP/badges, publishes portfolios.
2. **Teacher:** Monitors class roster progress, views student portfolios, identifies struggling learners.
3. **Parent:** Views family progress summaries, child project showcases, and child learning streaks.
4. **Admin:** Manages course curriculum, system users, and audit logs.
