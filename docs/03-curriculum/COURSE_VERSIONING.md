# COURSE VERSIONING & DEPRECATION POLICY

## 1. Principles of Course Versioning
Web technologies evolve over time (e.g. HTML5 → modern web standards, CSS Flexbox → Grid, JS ES6 → ES2026).

To avoid breaking an active student's learning progress:
```text
Course
 ├── Course Version (e.g., Web Creator Foundations 2026)
 ├── Content Version (v1.2.0)
 └── Technology Track (HTML5 / CSS3 / ES2026)
```

## 2. Deprecation Rules
- Active student enrollments are tied to specific Course Version IDs.
- Updating course content creates a new `CourseVersion` without deleting existing progress logs.
- Students receive an in-app prompt offering an upgrade to the latest curriculum edition.
