# Age Progression Curriculum

## Overview
The curriculum is designed to evolve alongside the cognitive development and maturity of the students. The platform guides students from basic digital literacy and visual programming up to professional-grade software engineering.

## Educational Progression

### Grades 5–6 (Ages 10-12)
**Focus:** Digital Foundations & Creative Computing
- **Core Topics:** 
  - Scratch / Blockly (Visual block-based programming)
  - Basic Logic and Sequencing
  - Problem Solving Fundamentals
  - Digital Safety & Citizenship
- **Platform Experience:** Highly visual, heavy use of gamified practice, strict safety controls, parent-monitored.

### Grades 7–8 (Ages 12-14)
**Focus:** Web Creation & Computational Thinking
- **Core Topics:**
  - HTML (Structure)
  - CSS (Styling)
  - JavaScript Fundamentals (Variables, loops, basic functions)
  - Introduction to Version Control (Basic Git concepts like history and saving changes)
- **Platform Experience:** Transitioning from blocks to text-based code in a safe, browser-based environment. Introduction to building small, shareable projects.

### Grades 9–10 (Ages 14-16)
**Focus:** Serious Web Development & Engineering Habits
- **Core Topics:**
  - Advanced JavaScript & Introduction to TypeScript
  - Frameworks (e.g., React basics)
  - APIs and Data Fetching
  - Databases (Basic SQL)
  - Testing Fundamentals
  - Git/GitHub (Commits, branching, pushing)
  - Deployment basics
  - AI Literacy (How to use AI tools responsibly)
- **Platform Experience:** Use of professional tools within the browser. Focus on building realistic applications and establishing a public portfolio.

### Grades 11–12 (Ages 16-18)
**Focus:** Advanced Builder Tracks & Career Readiness
- **Core Topics (Specialized Tracks):**
  - Full-Stack Development
  - Python & Backend Engineering
  - Data Science & AI Foundations
  - Cybersecurity Basics
  - Cloud Infrastructure
  - Product Building & Entrepreneurship
  - Open Source Contribution
- **Platform Experience:** High autonomy. Complex, multi-stage projects. Direct integration with GitHub and real-world deployment platforms. Preparation for university or junior developer roles.
