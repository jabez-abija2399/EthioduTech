# GIT & VERSION CONTROL PROGRESSION

## 1. Progressive Git Learning Ladder

```text
GRADES 5–6: Local Snapshots & History
 └── Platform-managed automatic save checkpoints in IndexedDB.

GRADES 7–8: Concept of Commits & Branches
 └── Conceptual introduction to "Checkpoints", "Saving Versions", and "Portfolio Revisions".

GRADES 9–10: Real Git & GitHub Integration
 └── Terminal Git commands (`git commit`, `git push`), GitHub authentication, and repository creation.

GRADES 11–12: Professional Open Source & Peer Review
 └── Branching strategies, Pull Requests, Code Reviews, and CI/CD basics.
```
